กล่องรายการติ๊ก (CheckedListBox)

ในกล่องเครื่องมือ: กล่องรายการติ๊ก · เทียบกับ WinForms: CheckedListBox

รายการที่แต่ละบรรทัดมีช่องติ๊ก เหมาะกับให้ผู้ใช้เลือกหลายอย่างจากรายการยาว ๆ เช่น หน้าท็อปปิ้งพิซซ่า วิชาที่จะลงเรียน

  • ใส่รายการตอนออกแบบใน Items (บรรทัดละรายการ) หรือในโค้ดด้วย items_add
  • รายการนับจาก 0: บรรทัดแรกคือ 0 บรรทัดที่สองคือ 1 …
  • checked_indices() ได้ตำแหน่งของทุกบรรทัดที่ติ๊กไว้

อยู่ในกล่องเครื่องมือกลุ่ม คอนโทรลทั่วไป (Common controls) - ลากมาวางบนฟอร์ม แล้วตั้ง Id (ชื่อที่ใช้ในโค้ด) ในหน้าต่าง Properties · ในโค้ดเรียกมันว่า ui.ชื่อId ซึ่งเป็นชนิด phai_ui::ctl::CheckedListBox

ตัวอย่าง

1. ใส่รายการตอนเปิดหน้าต่าง

ใส่ห้ารายการ แล้วติ๊กบรรทัดแรกไว้ให้:

fn loaded(&mut self, ui: &CheckedlistDemoUi) {
    for t in ["Cheese", "Ham", "Mushroom", "Pineapple", "Olives"] {
        ui.toppings.items_add(t);
    }
    ui.toppings.set_checked(0, true); // cheese, ticked from the start
}

2. อ่านว่าติ๊กอะไรไว้บ้าง

ได้ตำแหน่งที่ติ๊กเป็น Vec<usize> แล้วแปลงเป็นชื่อด้วย item(i):

fn order_clicked(&mut self, ui: &CheckedlistDemoUi) {
    let chosen: Vec<String> = ui.toppings.checked_indices().into_iter().map(|i| ui.toppings.item(i)).collect();
    if chosen.is_empty() {
        ui.summary.set_text("Nothing ticked yet.");
    } else {
        ui.summary.set_text(&format!("A pizza with {}.", chosen.join(", ")));
    }
}

หน้าต่างตัวอย่างทั้งหมด: checkedlist_demo.phaiform กับ checkedlist_demo.rs ในโปรเจกต์ docs/help-src/examples/controls - รันด้วย cargo run -- checkedlist

Events

ดับเบิลคลิกชื่อ event ในแท็บ Events ของ Properties แล้ว Phai Studio จะเขียน method ให้ (ชื่อในตารางนี้สมมติว่า Id ของมันคือ checkedlist และอยู่บนฟอร์ม MainWindow) - ชี้เมาส์ที่ชนิดของ e เพื่อดูชื่อเต็ม
