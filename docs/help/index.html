Phai Studio

ใช้งาน Phai Studio ตกแต่งหน้าตาด้วย CSS ทำงานกับฐานข้อมูล เขียนโค้ดกับ control control และความสามารถเพิ่มเติม ตัวตรวจสด (F12) เว็บและมือถือ (PWA) รายงานพิมพ์

Rust Language

1. เริ่มต้นกับ Rust 2. ตัวแปร ชนิดข้อมูล ฟังก์ชัน 3. เงื่อนไขและการวนซ้ำ 4. Ownership และการยืม 5. struct, enum และ match 6. จัดการข้อผิดพลาด 7. Vec, String, HashMap 8. trait และ generic 9. โมดูล crate และเทสต์ 10. อ่าน error ของคอมไพเลอร์ 11. เธรด และก้าวต่อไป

คู่มือ Phai Studio

เครื่องมือฟรีสำหรับเขียนโปรแกรม Windows ด้วยภาษา Rust และบทเรียน Rust ภาษาไทยสำหรับคนที่เพิ่งเริ่ม

เริ่มจากตรงไหนดี

ใช้งาน Phai Studioสร้างโปรเจกต์ ออกแบบหน้าต่าง เขียนโค้ด รัน และดีบัก เรียน Rust ตั้งแต่ศูนย์11 บท ตั้งแต่ตัวแปรไปจนถึงเธรด พร้อมแบบฝึกหัด อ่าน error ของคอมไพเลอร์เจอข้อความแดง ๆ แล้วไม่รู้จะทำอะไร เปิดหน้านี้ ตกแต่งหน้าตาด้วย CSSสี เส้นขอบ มุมมน ของทั้งโปรแกรม จากไฟล์เดียว ทำงานกับฐานข้อมูลMySQL, PostgreSQL, SQLite ดูตาราง รัน SQL และสร้างโค้ดให้ เขียนโค้ดกับ controlProperties, Methods, Events ชนิดของ control ในโค้ด และงานบน thread อื่นด้วย invoke control และความสามารถเพิ่มเติมการพิมพ์ ผูกข้อมูล user control เมนู MDI และอื่น ๆ เว็บและมือถือ (PWA)โปรแกรมเดิมรันในเบราว์เซอร์ ลองบนมือถือด้วย QR code ติดตั้งเป็นแอปได้ รายงานพิมพ์ออกแบบรายงานด้วยแถบ กลุ่ม ผลรวม ดูตัวอย่าง พิมพ์ และบันทึก PDF

ถ้าคุณไม่เคยเขียนโปรแกรมเลย

ไม่เป็นไรครับ คู่มือนี้เขียนให้คนที่เริ่มจากศูนย์อ่านได้ แนะนำให้ทำตามลำดับนี้:

  1. อ่าน ใช้งาน Phai Studio แล้วลองสร้างโปรเจกต์แรก ลากปุ่มลงฟอร์ม กด F5 ให้เห็นหน้าต่างของตัวเองก่อน
  2. เรียนบทที่ 1 ถึง 3 ทำแบบฝึกหัด "ลองทำ" ทุกข้อ พิมพ์เองอย่าคัดลอก
  3. บทที่ 4 (Ownership) คือหัวใจของ Rust อ่านช้า ๆ ถ้ายังไม่เข้าใจทั้งหมดก็ไปต่อได้ แล้วค่อยย้อนกลับมา
  4. เมื่อเจอ error ให้เปิดบทที่ 10 คอมไพเลอร์ของ Rust ไม่ได้ดุ มันกำลังช่วยคุณ
Rust ยากกว่าภาษาอื่นบางภาษาในช่วงแรก เพราะคอมไพเลอร์เข้มงวดมาก แต่ความเข้มงวดนั้นแหละที่ทำให้โปรแกรมที่ผ่านคอมไพล์แล้ว แทบไม่พังแบบงง ๆ ตอนใช้งานจริง ช่วงแรกจะรู้สึกว่าโดนติบ่อย นั่นเป็นเรื่องปกติของทุกคน

อยากอ่านเพิ่ม

  • The Rust Programming Language หนังสือทางการของ Rust (ภาษาอังกฤษ) ละเอียดที่สุด
  • Rust by Example เรียนจากตัวอย่างสั้น ๆ
  • เอกสารไลบรารีมาตรฐาน ไว้ค้นว่าแต่ละฟังก์ชันทำอะไร
