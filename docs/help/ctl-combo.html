รายการเลือก (ComboBox)

ในกล่องเครื่องมือ: รายการเลือก · เทียบกับ WinForms: ComboBox

กล่องที่กดแล้วมีรายการเลื่อนลงมาให้เลือกหนึ่งอย่าง ใช้พื้นที่บนหน้าต่างน้อย เหมาะกับรายการที่ไม่ยาวเกินไป เช่น จังหวัด ขนาดเสื้อ

  • ใส่รายการตอนออกแบบใน Items หรือในโค้ดด้วย items_add
  • DropDownStyle: DropDown พิมพ์เองได้ด้วย · DropDownList เลือกจากรายการเท่านั้น
  • ดับเบิลคลิกในตัวออกแบบ ได้ method ตอนเลือกเปลี่ยน (…_changed)
  • selected_index() ได้ Option<usize> - None คือยังไม่ได้เลือก

อยู่ในกล่องเครื่องมือกลุ่ม คอนโทรลทั่วไป (Common controls) - ลากมาวางบนฟอร์ม แล้วตั้ง Id (ชื่อที่ใช้ในโค้ด) ในหน้าต่าง Properties · ในโค้ดเรียกมันว่า ui.ชื่อId ซึ่งเป็นชนิด phai_ui::ctl::ComboBox

ตัวอย่าง

1. เลือกแล้วแสดงสิ่งที่เลือก

selected_item() ได้ข้อความของรายการที่เลือก ถ้ายังไม่ได้เลือกเป็น None:

fn fruit_changed(&mut self, ui: &ComboDemoUi) {
    // The item chosen, if there is one.
    if let Some(f) = ui.fruit.selected_item() {
        ui.chosen.set_text(&format!("You chose {f}."));
    }
}

2. เพิ่มรายการเอง

ไม่ให้เพิ่มคำว่าง และไม่ให้ซ้ำ (find_string_exact) เพิ่มแล้วเลือกให้เลย:

fn add_clicked(&mut self, ui: &ComboDemoUi) {
    let name = ui.new_fruit.text();
    let name = name.trim();
    if name.is_empty() || ui.fruit.find_string_exact(name).is_some() {
        return; // nothing typed, or already in the list
    }
    let at = ui.fruit.items_add(name);
    ui.fruit.set_selected_index(Some(at)); // and chosen
    self.fruit_changed(ui);
    ui.new_fruit.set_text("");
}

หน้าต่างตัวอย่างทั้งหมด: combo_demo.phaiform กับ combo_demo.rs ในโปรเจกต์ docs/help-src/examples/controls - รันด้วย cargo run -- combo

Events

ดับเบิลคลิกชื่อ event ในแท็บ Events ของ Properties แล้ว Phai Studio จะเขียน method ให้ (ชื่อในตารางนี้สมมติว่า Id ของมันคือ combo และอยู่บนฟอร์ม MainWindow) - ชี้เมาส์ที่ชนิดของ e เพื่อดูชื่อเต็ม
