Phai Studio

ใช้งาน Phai Studio ตกแต่งหน้าตาด้วย CSS ทำงานกับฐานข้อมูล

เรียน Rust

1. เริ่มต้นกับ Rust 2. ตัวแปร ชนิดข้อมูล ฟังก์ชัน 3. เงื่อนไขและการวนซ้ำ 4. Ownership และการยืม 5. struct, enum และ match 6. จัดการข้อผิดพลาด 7. Vec, String, HashMap 8. trait และ generic 9. โมดูล crate และเทสต์ 10. อ่าน error ของคอมไพเลอร์ 11. เธรด และก้าวต่อไป

ทำงานกับฐานข้อมูล

หน้าต่าง Server Explorer ของ Phai Studio ต่อฐานข้อมูล MySQL / MariaDB, PostgreSQL และไฟล์ SQLite ได้ ดูตาราง ดูข้อมูล เขียนคำสั่ง SQL และสร้างโค้ด Rust สำหรับอ่านตารางให้ เหมือน Server Explorer ของ Visual Studio

เปิด Server Explorer

เมนู View > Server Explorer หรือ Data > Server Explorer หรือกด Ctrl+Alt+S หน้าต่างจะอยู่ข้างหน้าต่าง Project มีหัวข้อ Data Connections เป็นรากของทุกการเชื่อมต่อ

เพิ่มการเชื่อมต่อ

  1. Data > Add Connection... หรือคลิกขวาที่ Data Connections แล้วเลือก Add Connection...
  2. เลือกชนิด: MySQL / MariaDB, PostgreSQL หรือ SQLite file...
  3. ถ้าเป็น MySQL หรือ PostgreSQL กรอก Server (เช่น localhost) Port User Password และ Database (เว้นว่างได้ จะเห็นทุกฐานข้อมูลที่มีสิทธิ์)
  4. ถ้าเป็น SQLite เลือกไฟล์ .db ที่มีอยู่ หรือพิมพ์ชื่อไฟล์ใหม่ SQLite จะสร้างให้
  5. Phai Studio ลองเชื่อมต่อก่อนเก็บ ถ้าสำเร็จจะบอกชนิดและเวอร์ชันของฐานข้อมูลที่แถบสถานะ
ฐานข้อมูลพอร์ตปกติผู้ใช้ที่ใส่ไว้ให้
MySQL / MariaDB3306root
PostgreSQL5432postgres
SQLiteไม่มี (เป็นไฟล์)ไม่มี
ถ้าต่อเซิร์ฟเวอร์ข้ามอินเทอร์เน็ต ให้ติ๊ก Encrypt the connection (TLS) ข้อมูลกับรหัสผ่านจะถูกเข้ารหัสระหว่างทาง ส่วน Trust the server's own certificate ใช้กับเซิร์ฟเวอร์ที่ใช้ใบรับรองที่ทำเอง Phai Studio จำการเชื่อมต่อไว้ให้ รหัสผ่านถูกเก็บแบบเข้ารหัสด้วยระบบของ Windows

ดูโครงสร้าง

กดลูกศรหน้าการเชื่อมต่อ จะเห็นฐานข้อมูล ใต้ฐานข้อมูลคือตารางและ view ใต้ตารางคือคอลัมน์ พร้อมชนิดข้อมูล และบอกว่าเป็นคีย์หลักหรือเว้นว่างได้ไหม Phai Studio อ่านจากเซิร์ฟเวอร์ตอนเปิดกิ่งนั้นครั้งแรก ถ้ามีคนแก้ฐานข้อมูลระหว่างนั้น คลิกขวาแล้วเลือก Refresh

  • Design Table เปิดตัวออกแบบตาราง (Table Designer) แบบ Visual Studio เป็นตารางของคอลัมน์ แก้ชื่อ ชนิดข้อมูล เว้นว่างได้ไหม คีย์หลัก ตัวเลขรันอัตโนมัติ และค่าเริ่มต้น ได้ด้วยการคลิก ด้านล่างมี index และ foreign key และมีคำสั่ง SQL ที่จะใช้แก้ตาราง เขียนให้ดูไปพร้อมกัน กด Update เพื่อแก้ตารางจริง
  • New Table... เปิดตัวออกแบบตารางเดียวกัน สำหรับสร้างตารางใหม่ในฐานข้อมูลนั้น
  • Script as SQL เปิดคำสั่ง CREATE TABLE ของตารางนี้ พร้อมตัวอย่างคำสั่งแก้ตารางที่ใส่ -- ไว้ เอา -- หน้าบรรทัดที่ต้องการออก แล้วกด Ctrl+Shift+E เพื่อแก้ตาราง

เขียนและรันคำสั่ง SQL

  1. Data > New Query หรือคลิกขวาแล้ว New Query จะเปิดไฟล์ Query1.sql บรรทัดแรกบอกว่าต่อกับเซิร์ฟเวอร์และฐานข้อมูลไหน
  2. พิมพ์คำสั่ง เช่น SELECT * FROM customers WHERE active = 1;
  3. กด Ctrl+Shift+E (Data > Execute Query) ผลลัพธ์จะขึ้นที่แท็บ Results ถ้าเป็นคำสั่งแก้ข้อมูล จะบอกว่าเปลี่ยนไปกี่แถว

ใส่หลายคำสั่งในไฟล์เดียวได้ ผลที่แสดงคือผลของคำสั่งสุดท้ายที่มีแถวข้อมูล

คำสั่ง UPDATE และ DELETE ที่ไม่มี WHERE จะแก้หรือลบทุกแถวในตาราง ควรลองกับฐานข้อมูลทดลองก่อน และสำรองข้อมูลจริงไว้เสมอ

ใส่ตารางลงฟอร์ม (Data binding)

วิธีที่เร็วที่สุดในการทำโปรแกรมจัดการข้อมูล เหมือนลากตารางจากหน้าต่าง Data Sources ของ Visual Studio:

  1. เปิดฟอร์มของโปรเจกต์ไว้ในตัวออกแบบ
  2. ใน Server Explorer คลิกขวาที่ตาราง แล้วเลือก Add to Form
  3. Phai Studio วางตารางข้อมูล (Data grid) ที่ผูกกับตารางนั้นลงในฟอร์ม พร้อมปุ่ม Reload และ Save ด้านล่าง แล้วกด Ctrl+S บันทึกฟอร์ม
  4. กด F5 โปรแกรมจะโหลดข้อมูลมาแสดงเองตอนเปิดหน้าต่าง

ในโปรแกรมที่รัน:

  • ดับเบิลคลิกช่องเพื่อแก้ค่า กด Enter เพื่อเก็บ
  • ดับเบิลคลิกใต้แถวสุดท้ายเพื่อเพิ่มแถวใหม่ ช่องที่เว้นว่างจะใช้ค่าเริ่มต้นของตาราง เช่น รหัสที่รันเอง
  • เลือกแถวแล้วกด Delete เพื่อเอาแถวออก
  • กด Save เพื่อบันทึกทุกอย่างที่แก้ลงฐานข้อมูลทีเดียว แล้วโหลดใหม่ให้ ถ้ายังไม่กด Save ข้อมูลในฐานข้อมูลยังไม่เปลี่ยน กด Reload เพื่อทิ้งที่แก้และโหลดใหม่
  • ช่องที่เขียนว่า NULL คือไม่มีค่า

ครั้งแรกที่ใส่ตารางลงฟอร์ม Phai Studio เตรียมโปรเจกต์ให้ด้วย:

  • src/data_sources.rs บอกว่าข้อมูลอยู่ที่เซิร์ฟเวอร์ไหน (เหมือน connection string ของ WinForms) แก้ไฟล์นี้ได้ เช่น ตอนย้ายไปใช้เซิร์ฟเวอร์จริง รหัสผ่านไม่ได้เขียนไว้ในไฟล์ แต่อ่านจากตัวแปรสภาพแวดล้อม PHAI_DB_PASSWORD
  • เพิ่ม phai-data ใน Cargo.toml และ mod data_sources; ใน main.rs
  • เพิ่มคำแปลไทยของปุ่ม Reload และ Save ในตารางคำแปล

ในโค้ดของฟอร์มสั่งเองได้ด้วย ui.reload_customers() และ ui.save_customers() (ชื่อตามตาราง) หัวคอลัมน์แสดงชื่อคอลัมน์ในฐานข้อมูลตามจริง ถ้าแก้หัวคอลัมน์ในฟอร์มเป็นคำอื่น คำนั้นจะแปลไทยได้เหมือนข้อความอื่น

การแก้และลบแถวต้องรู้ว่าแถวไหนคือแถวไหน ตารางจึงต้องมีคีย์หลัก (primary key) ตารางที่ไม่มีคีย์หลักจะเพิ่มแถวได้อย่างเดียว ถ้าเป็น SQLite โปรแกรมจะเปิดไฟล์ฐานข้อมูลตามพาธที่เลือกตอนเพิ่มการเชื่อมต่อ ถ้าจะแจกโปรแกรม ให้แก้พาธใน data_sources.rs ให้ชี้ไปที่ไฟล์บนเครื่องผู้ใช้

ให้โปรแกรมของคุณอ่านฐานข้อมูล

คลิกขวาที่ตาราง แล้วเลือก Copy code for a program Phai Studio จะคัดลอกโค้ด Rust ลงคลิปบอร์ดให้ วางในไฟล์ของคุณได้เลย ในโค้ดมี:

  • ฟังก์ชัน connection() ที่บอกว่าต่อเซิร์ฟเวอร์ไหน
  • struct หนึ่งแถวของตาราง ชื่อฟิลด์และชนิดตรงกับคอลัมน์ คอลัมน์ที่เว้นว่างได้จะเป็น Option
  • ฟังก์ชัน all_ชื่อตาราง() ที่อ่านทุกแถว คืนค่าเป็น Vec ของ struct นั้น

โค้ดนี้ใช้ phai-data ตัวเดียวกับที่ Server Explorer ใช้ ให้เพิ่มใน Cargo.toml ของโปรเจกต์ตามบรรทัดแรกของโค้ด

โค้ดที่สร้างให้ไม่ได้เขียนรหัสผ่านลงในโค้ด แต่อ่านจากตัวแปรสภาพแวดล้อม PHAI_DB_PASSWORD เพราะโค้ดมักถูกแชร์หรือขึ้น Git รหัสผ่านไม่ควรอยู่ในนั้น

ลองทำ: สมุดรายชื่อลูกค้าด้วย SQLite

SQLite ไม่ต้องติดตั้งเซิร์ฟเวอร์ ฐานข้อมูลทั้งก้อนเป็นไฟล์เดียว เหมาะกับการหัด

  1. Data > Add Connection... เลือก SQLite file... แล้วตั้งชื่อไฟล์ใหม่ shop.db
  2. คลิกขวาที่การเชื่อมต่อ แล้ว New Query พิมพ์คำสั่งข้างล่าง แล้วกด Ctrl+Shift+E
CREATE TABLE customers (
    id    INTEGER PRIMARY KEY,
    name  TEXT NOT NULL,
    phone TEXT
);
INSERT INTO customers (name, phone) VALUES ('สมชาย ใจดี', '081-234-5678');
INSERT INTO customers (name, phone) VALUES ('Monrak Net', '02-111-2222');
SELECT * FROM customers;
  1. ดูผลที่แท็บ Results แล้วคลิกขวาที่การเชื่อมต่อ เลือก Refresh จะเห็นตาราง customers
  2. เปิดฟอร์มหลักของโปรเจกต์ คลิกขวาที่ตาราง customers เลือก Add to Form บันทึกฟอร์ม แล้วกด F5 ลองแก้ชื่อลูกค้า เพิ่มลูกค้าใหม่ แล้วกด Save
