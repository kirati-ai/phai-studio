ไม่พบหน้าที่ตรงกัน

ทำงานกับฐานข้อมูล

หน้าต่าง Server Explorer ของ Phai Studio ต่อฐานข้อมูล MySQL / MariaDB, PostgreSQL และไฟล์ SQLite ได้ ดูตาราง ดูข้อมูล เขียนคำสั่ง SQL และสร้างโค้ด Rust สำหรับอ่านตารางให้ เหมือน Server Explorer ของ Visual Studio

เปิด Server Explorer

เมนู View > Server Explorer หรือ Data > Server Explorer หรือกด Ctrl+Alt+S หน้าต่างจะอยู่ข้างหน้าต่าง Project มีหัวข้อ Data Connections เป็นรากของทุกการเชื่อมต่อ

เพิ่มการเชื่อมต่อ

  1. Data > Add Connection... หรือคลิกขวาที่ Data Connections แล้วเลือก Add Connection...
  2. เลือกชนิด: MySQL / MariaDB, PostgreSQL หรือ SQLite file...
  3. ถ้าเป็น MySQL หรือ PostgreSQL กรอก Server (เช่น localhost) Port User Password และ Database (เว้นว่างได้ จะเห็นทุกฐานข้อมูลที่มีสิทธิ์)
  4. ถ้าเป็น SQLite เลือกไฟล์ .db ที่มีอยู่ หรือพิมพ์ชื่อไฟล์ใหม่ SQLite จะสร้างให้
  5. Phai Studio ลองเชื่อมต่อก่อนเก็บ ถ้าสำเร็จจะบอกชนิดและเวอร์ชันของฐานข้อมูลที่แถบสถานะ
ฐานข้อมูลพอร์ตปกติผู้ใช้ที่ใส่ไว้ให้

ถ้าต่อเซิร์ฟเวอร์ข้ามอินเทอร์เน็ต ให้ติ๊ก Encrypt the connection (TLS) ข้อมูลกับรหัสผ่านจะถูกเข้ารหัสระหว่างทาง ส่วน Trust the server's own certificate ใช้กับเซิร์ฟเวอร์ที่ใช้ใบรับรองที่ทำเอง Phai Studio จำการเชื่อมต่อไว้ให้ รหัสผ่านถูกเก็บแบบเข้ารหัสด้วยระบบของ Windows

ดูโครงสร้าง

กดลูกศรหน้าการเชื่อมต่อ จะเห็นฐานข้อมูล ใต้ฐานข้อมูลคือตารางและ view ใต้ตารางคือคอลัมน์ พร้อมชนิดข้อมูล และบอกว่าเป็นคีย์หลักหรือเว้นว่างได้ไหม Phai Studio อ่านจากเซิร์ฟเวอร์ตอนเปิดกิ่งนั้นครั้งแรก ถ้ามีคนแก้ฐานข้อมูลระหว่างนั้น คลิกขวาแล้วเลือก Refresh

ฐานข้อมูลNew Query, New Table..., Refresh

viewShow Table Data, New Query, Refresh
  • Show Table Data แสดงข้อมูลในตาราง ที่แท็บ Results ด้านล่าง แก้ค่าในตารางผลลัพธ์ได้โดยตรง
  • Design Table เปิดตัวออกแบบฐานข้อมูล (Database Designer) เป็นหน้าต่างของตัวเอง ด้านซ้ายเลือกฐานข้อมูลและตารางได้แบบ phpMyAdmin ด้านขวาเป็นแท็บ Columns, Indexes และ Foreign Keys แก้ชื่อ ชนิดข้อมูล เว้นว่างได้ไหม คีย์หลัก ตัวเลขรันอัตโนมัติ และค่าเริ่มต้น ได้ด้วยการคลิก ด้านล่างมีคำสั่ง SQL ที่จะใช้แก้ตาราง เขียนให้ดูไปพร้อมกัน กด Update หรือ Ctrl+S เพื่อแก้ตารางจริง
  • New Table... เปิดตัวออกแบบเดียวกัน สำหรับสร้างตารางใหม่ในฐานข้อมูลนั้น
  • New Database... (คลิกขวาที่การเชื่อมต่อ หรือปุ่มในตัวออกแบบ) สร้างฐานข้อมูลใหม่ MySQL ใช้ utf8mb4 PostgreSQL ใช้ UTF8 เก็บภาษาไทยได้ สร้างเสร็จเปิดตารางแรกให้ออกแบบต่อ ถ้าการเชื่อมต่อไม่ได้ระบุฐานข้อมูลและบนเซิร์ฟเวอร์ยังไม่มีเลย Phai Studio จะให้สร้างก่อน
  • Close Connection พับการเชื่อมต่อและปล่อยที่อ่านไว้ กางออกอีกครั้งเพื่อเชื่อมต่อใหม่
  • Script as SQL เปิดคำสั่ง CREATE TABLE ของตารางนี้ พร้อมตัวอย่างคำสั่งแก้ตารางที่ใส่ -- ไว้ เอา -- หน้าบรรทัดที่ต้องการออก แล้วกด Ctrl+Shift+E เพื่อแก้ตาราง

เขียนและรันคำสั่ง SQL

  1. Data > New Query หรือคลิกขวาแล้ว New Query จะเปิดไฟล์ Query1.sql บรรทัดแรกบอกว่าต่อกับเซิร์ฟเวอร์และฐานข้อมูลไหน
  2. พิมพ์คำสั่ง เช่น SELECT * FROM customers WHERE active = 1;
  3. กด Ctrl+Shift+E (Data > Execute Query) ผลลัพธ์จะขึ้นที่แท็บ Results ถ้าเป็นคำสั่งแก้ข้อมูล จะบอกว่าเปลี่ยนไปกี่แถว

ใส่หลายคำสั่งในไฟล์เดียวได้ ผลที่แสดงคือผลของคำสั่งสุดท้ายที่มีแถวข้อมูล

คำสั่ง UPDATE และ DELETE ที่ไม่มี WHERE จะแก้หรือลบทุกแถวในตาราง ควรลองกับฐานข้อมูลทดลองก่อน และสำรองข้อมูลจริงไว้เสมอ

ใส่ตารางลงฟอร์ม (Data binding)

วิธีที่เร็วที่สุดในการทำโปรแกรมจัดการข้อมูล เหมือนลากตารางจากหน้าต่าง Data Sources ของ Visual Studio:

  1. เปิดฟอร์มของโปรเจกต์ไว้ในตัวออกแบบ
  2. ใน Server Explorer คลิกขวาที่ตาราง แล้วเลือก Add to Form
  3. Phai Studio วางตารางข้อมูล (Data grid) ที่ผูกกับตารางนั้นลงในฟอร์ม พร้อมปุ่ม Reload และ Save ด้านล่าง แล้วกด Ctrl+S บันทึกฟอร์ม
  4. กด F5 โปรแกรมจะโหลดข้อมูลมาแสดงเองตอนเปิดหน้าต่าง

ในโปรแกรมที่รัน:

  • ดับเบิลคลิกช่องเพื่อแก้ค่า กด Enter เพื่อเก็บ
  • ดับเบิลคลิกใต้แถวสุดท้ายเพื่อเพิ่มแถวใหม่ ช่องที่เว้นว่างจะใช้ค่าเริ่มต้นของตาราง เช่น รหัสที่รันเอง
  • เลือกแถวแล้วกด Delete เพื่อเอาแถวออก
  • กด Save เพื่อบันทึกทุกอย่างที่แก้ลงฐานข้อมูลทีเดียว แล้วโหลดใหม่ให้ ถ้ายังไม่กด Save ข้อมูลในฐานข้อมูลยังไม่เปลี่ยน กด Reload เพื่อทิ้งที่แก้และโหลดใหม่
  • ช่องที่เขียนว่า NULL คือไม่มีค่า

ครั้งแรกที่ใส่ตารางลงฟอร์ม Phai Studio เตรียมโปรเจกต์ให้ด้วย:

  • src/data_sources.rs บอกว่าข้อมูลอยู่ที่เซิร์ฟเวอร์ไหน (เหมือน connection string ของ WinForms) แก้ไฟล์นี้ได้ เช่น ตอนย้ายไปใช้เซิร์ฟเวอร์จริง รหัสผ่านไม่ได้เขียนไว้ในไฟล์ แต่อ่านจากตัวแปรสภาพแวดล้อม PHAI_DB_PASSWORD
  • เพิ่ม phai-data ใน Cargo.toml และ mod data_sources; ใน main.rs
  • เพิ่มคำแปลไทยของปุ่ม Reload และ Save ในตารางคำแปล

ในโค้ดของฟอร์มสั่งเองได้ด้วย ui.reload_customers() และ ui.save_customers() (ชื่อตามตาราง) การบันทึกทำใน transaction เดียว: ถ้าแถวไหนบันทึกไม่ได้ (เช่น ช่องที่ห้ามว่าง) จะไม่มีอะไรถูกบันทึกเลย ฐานข้อมูลเหมือนเดิม แก้แล้วกดบันทึกใหม่ได้ (MySQL ต้องเป็นตาราง InnoDB ซึ่งเป็นค่าเริ่มต้น)

หลายคนใช้พร้อมกัน: ก่อนบันทึก โปรแกรมอ่านแถวที่เราแก้หรือลบจากฐานข้อมูลอีกครั้ง ถ้ามีคนอื่นแก้ช่องเดียวกัน แก้แถวที่เราจะลบ หรือลบแถวที่เราแก้ไปก่อน จะไม่บันทึกอะไรเลยและบอกว่าแถวไหน ให้กดโหลดใหม่แล้วแก้อีกครั้ง ส่วนถ้าคนอื่นแก้ช่องอื่นของแถวเดียวกัน ของทั้งสองคนจะอยู่ครบ ไม่ทับกัน หัวคอลัมน์แสดงชื่อคอลัมน์ในฐานข้อมูลตามจริง ถ้าแก้หัวคอลัมน์ในฟอร์มเป็นคำอื่น คำนั้นจะแปลไทยได้เหมือนข้อความอื่น

การแก้และลบแถวต้องรู้ว่าแถวไหนคือแถวไหน ตารางจึงต้องมีคีย์หลัก (primary key) ตารางที่ไม่มีคีย์หลักจะเพิ่มแถวได้อย่างเดียว ถ้าเป็น SQLite โปรแกรมจะเปิดไฟล์ฐานข้อมูลตามพาธที่เลือกตอนเพิ่มการเชื่อมต่อ ถ้าจะแจกโปรแกรม ให้แก้พาธใน data_sources.rs ให้ชี้ไปที่ไฟล์บนเครื่องผู้ใช้

ตกแต่ง Data grid แบบ DevExpress

Data grid ของ Phai Studio ตั้งค่าได้ทั้งตารางและทีละคอลัมน์ คล้าย GridControl ของ DevExpress ทุกอย่างที่ตั้งในตัวออกแบบ จะเหมือนกันตอนโปรแกรมรัน

ทีละคอลัมน์ เลือก grid แล้วกด ... ที่ Columns ในหน้าต่าง Properties (หรือ Edit Columns... จากปุ่มลูกศรเล็กที่มุม grid) จะเปิดหน้าต่าง Grid Columns ด้านซ้ายเป็นรายการคอลัมน์ มีปุ่ม Add, Remove, Move Up, Move Down และ Retrieve Fields ที่ดึงฟิลด์ของตารางที่ผูกไว้มาให้ ด้านขวาเป็นค่าของคอลัมน์ที่เลือก:

ค่าใช้ทำอะไร

Sorted, ปุ่มเรียง, ลากความกว้างเรียงตอนเปิด, คลิกหัวคอลัมน์เพื่อเรียงได้ไหม, ลากขอบหัวคอลัมน์ได้ไหม

ทั้งตาราง อยู่ในหน้าต่าง Properties: AlternateRowColor (สีแถวเว้นแถว), HeaderBackColor และ HeaderForeColor (สีหัวตาราง), RowHeight, ShowFooter, ShowColumnHeaders, ColumnAutoWidth, AllowAddRows, AllowDeleteRows, EditorShowMode (ดับเบิลคลิก คลิก หรือ F2), EnterMoveNextColumn, AllowColumnMoving, FindPanel, FindFilter, CopyColumnHeaders และ Border colour / Border width สำหรับเส้นขอบ

ในโปรแกรมที่รัน:

  • Ctrl+F เปิดช่องค้นหาเหนือหัวตาราง พิมพ์แล้วเหลือเฉพาะแถวที่มีคำนั้น (ปิด FindFilter ถ้าอยากแค่ไฮไลต์) Enter ไปแถวถัดไป Esc ปิด แถวที่ถูกกรองออกยังอยู่ กด Save ก็บันทึกด้วย
  • คลิกหัวคอลัมน์เพื่อเรียง คลิกอีกครั้งเพื่อกลับด้าน
  • Ctrl+C คัดลอกแถวที่เลือกพร้อมหัวคอลัมน์ วางใน Excel ได้เลย Ctrl+V วางจาก Excel ลงตาราง Ctrl+A เลือกทุกแถว
  • ตัวกรองแบบ Excel (AllowFilter): ชี้ที่หัวคอลัมน์จะเห็นปุ่มลูกศร กดแล้วได้รายการค่าทั้งหมดในคอลัมน์นั้นให้ติ๊ก มีช่องค้นหา ปุ่มเรียง ก-ฮ / ฮ-ก และ "ล้างตัวกรอง" คอลัมน์ที่กรองอยู่มีรูปกรวยบนหัว ผลรวมท้ายตารางคิดเฉพาะแถวที่เหลือ กรองหลายคอลัมน์พร้อมกันได้
  • คลิกขวาที่หัวคอลัมน์ (HeaderMenu): เรียง, กรอง..., ล้างตัวกรอง, จัดกลุ่มตามคอลัมน์นี้, ส่งออกเป็น Excel (.xlsx ตัวเลขและวันที่ยังเป็นตัวเลขจริง คำนวณต่อได้ หัวตารางตรึงไว้และมีปุ่มกรองของ Excel), ส่งออกเป็น PDF, ส่งออกเป็น CSV และตัวอย่างก่อนพิมพ์

ตารางหลัก-ตารางลูก (master-detail)

เช่น ตาราง orders (ใบสั่งซื้อ) กับ lines (รายการสินค้าในใบสั่งซื้อ) เลือก lines แล้วตั้ง MasterDetail ในหน้าต่าง Properties เป็น orders.id = order_id อ่านว่า ตารางนี้แสดงเฉพาะแถวที่คอลัมน์ order_id ตรงกับคอลัมน์ id ของแถวที่เลือกอยู่ในตาราง orders (ชื่อคอลัมน์ใช้ได้ทั้งหัวคอลัมน์และชื่อคอลัมน์ในฐานข้อมูล ถ้าชื่อเหมือนกันเขียนแค่ orders.id)

  • เลือกแถวอื่นในตารางหลัก ตารางลูกเปลี่ยนตามทันที ตารางลูกมีตารางลูกต่ออีกชั้นก็ได้
  • เพิ่มแถวใหม่ในตารางลูก (ดับเบิลคลิกใต้แถวสุดท้าย) คีย์ของตารางหลักใส่ให้เอง
  • แถวของใบอื่นไม่ได้หายไป แค่ไม่แสดง ตารางที่ผูกฐานข้อมูลกด Save ก็บันทึกครบทุกแถว

ในโค้ดสั่งได้ด้วย เช่น ui.customers.sort_by(1, true), ui.customers.find("สมชาย"), ui.customers.selected_rows(), ui.customers.export_csv("customers.csv") (เปิดใน Excel แล้วภาษาไทยไม่เพี้ยน), ui.customers.export_xlsx("customers.xlsx"), ui.customers.export_pdf("customers.pdf", "ลูกค้า"), ui.customers.print_preview("ลูกค้า"), ui.customers.set_column_filter(2, Some(&["Paid"])), ui.customers.clear_filters() และ ui.lines.set_master(ui.orders, 0, 1)

ในเว็บแอป (PWA) สีแถวเว้นแถว สีหัวตาราง การจัดวาง และคอลัมน์ที่ซ่อน แสดงเหมือนกัน ส่วนรูปแบบตัวเลข ผลรวม กฎสี การจัดกลุ่ม และช่องค้นหา มีเฉพาะโปรแกรม Windows

ให้โปรแกรมของคุณอ่านฐานข้อมูล

คลิกขวาที่ตาราง แล้วเลือก Copy code for a program Phai Studio จะคัดลอกโค้ด Rust ลงคลิปบอร์ดให้ วางในไฟล์ของคุณได้เลย ในโค้ดมี:

  • ฟังก์ชัน connection() ที่บอกว่าต่อเซิร์ฟเวอร์ไหน
  • struct หนึ่งแถวของตาราง ชื่อฟิลด์และชนิดตรงกับคอลัมน์ คอลัมน์ที่เว้นว่างได้จะเป็น Option
  • ฟังก์ชัน all_ชื่อตาราง() ที่อ่านทุกแถว คืนค่าเป็น Vec ของ struct นั้น

โค้ดนี้ใช้ phai-data ตัวเดียวกับที่ Server Explorer ใช้ ให้เพิ่มใน Cargo.toml ของโปรเจกต์ตามบรรทัดแรกของโค้ด

โค้ดที่สร้างให้ไม่ได้เขียนรหัสผ่านลงในโค้ด แต่อ่านจากตัวแปรสภาพแวดล้อม PHAI_DB_PASSWORD เพราะโค้ดมักถูกแชร์หรือขึ้น Git รหัสผ่านไม่ควรอยู่ในนั้น

SQLite ไม่ต้องติดตั้งเซิร์ฟเวอร์ ฐานข้อมูลทั้งก้อนเป็นไฟล์เดียว เหมาะกับการหัด

  2. คลิกขวาที่การเชื่อมต่อ แล้ว New Query พิมพ์คำสั่งข้างล่าง แล้วกด Ctrl+Shift+E

    id    INTEGER PRIMARY KEY,
    name  TEXT NOT NULL,
    phone TEXT
);
