Rust Language

1. เริ่มต้นกับ Rust 2. ตัวแปร ชนิดข้อมูล ฟังก์ชัน 3. เงื่อนไขและการวนซ้ำ 4. Ownership และการยืม 5. struct, enum และ match 6. จัดการข้อผิดพลาด 7. Vec, String, HashMap 8. trait และ generic 9. โมดูล crate และเทสต์ 10. อ่าน error ของคอมไพเลอร์ 11. เธรด และก้าวต่อไป

หน้าต่างเลือกโฟลเดอร์ (FolderBrowserDialog)

ในกล่องเครื่องมือ: หน้าต่างเลือกโฟลเดอร์ · เทียบกับ WinForms: FolderBrowserDialog

หน้าต่างเลือกโฟลเดอร์ของ Windows เช่น เลือกที่เก็บรูป ที่สำรองข้อมูล

  • show_dialog() ได้ Option<PathBuf> ของโฟลเดอร์ที่เลือก
  • InitialDirectory โฟลเดอร์ที่เปิดอยู่ตอนแรก

อยู่ในกล่องเครื่องมือกลุ่ม กล่องโต้ตอบ (Dialogs) - ลากมาวางแล้วมันจะไปอยู่ในแถบด้านล่างของตัวออกแบบ (ไม่ได้อยู่บนหน้าต่าง) · ในโค้ดเรียกมันว่า ui.ชื่อId ซึ่งเป็นชนิด phai_ui::ctl::FolderBrowserDialog

ตัวอย่าง

1. เลือกโฟลเดอร์แล้วนับของข้างใน

fn choose_clicked(&mut self, ui: &FolderbrowserdialogDemoUi) {
    let Some(folder) = ui.folder_dialog.show_dialog() else { return };
    // How many things are in it.
    let n = std::fs::read_dir(&folder).map(|d| d.count()).unwrap_or(0);
    ui.chosen.set_text(&format!("{} - {n} things in it", folder.display()));
}

หน้าต่างตัวอย่างทั้งหมด: folderbrowserdialog_demo.phaiform กับ folderbrowserdialog_demo.rs ในโปรเจกต์ docs/help-src/examples/controls - รันด้วย cargo run -- folderbrowserdialog

Method ของ FolderBrowserDialog

Methodทำอะไร
show_dialog(&self) -> Option<PathBuf>เปิดหน้าต่าง ได้โฟลเดอร์ที่เลือก - None เมื่อกด Cancel
