1. เริ่มต้นกับ Rust

Rust คืออะไร ทำไมถึงน่าเรียน และโปรแกรมแรกของคุณ

Rust คืออะไร

Rust เป็นภาษาโปรแกรมที่ได้โปรแกรมเร็วเท่า C และ C++ แต่ปลอดภัยกว่ามาก คอมไพเลอร์ของ Rust ตรวจโค้ดอย่างละเอียดก่อนจะยอมสร้างโปรแกรมให้ จึงจับบั๊กประเภทที่ภาษาอื่นปล่อยหลุดไปถึงผู้ใช้ได้ตั้งแต่ตอนเขียน เช่น ใช้หน่วยความจำที่คืนไปแล้ว ลืมจัดการกรณีที่ไม่มีค่า หรือสองเธรดแก้ข้อมูลเดียวกันพร้อมกัน

Rust ใช้สร้างได้ทั้งโปรแกรมบน Windows, เว็บเซิร์ฟเวอร์, เครื่องมือบรรทัดคำสั่ง, เกม ไปจนถึงระบบปฏิบัติการ

ภาษาคอมไพล์ หมายความว่าอะไร

โค้ด Rust ที่คุณเขียน (ไฟล์ .rs) คอมพิวเตอร์ยังรันไม่ได้ทันที ต้องผ่านคอมไพเลอร์ (rustc) ก่อน มันจะแปลงโค้ดเป็นไฟล์ .exe ที่รันได้เลย ขั้นตอนนี้เรียกว่า build ถ้าโค้ดผิด คอมไพเลอร์จะไม่ยอมสร้าง .exe และบอกว่าผิดตรงไหน

Cargo: ผู้ช่วยจัดการโปรเจกต์

ใน Rust แทบไม่มีใครเรียก rustc เอง เราใช้ Cargo ซึ่งมากับ Rust อยู่แล้ว Cargo ทำหน้าที่สร้างโปรเจกต์ build รันเทสต์ และดาวน์โหลดไลบรารี (ใน Rust เรียกไลบรารีว่า crate) จาก crates.io

คำสั่งทำอะไรใน Phai Studio
cargo new ชื่อสร้างโปรเจกต์ใหม่File > New project
cargo buildbuildCtrl+B
cargo runbuild แล้วรันCtrl+F5
cargo testรันเทสต์Ctrl+R, T
cargo add ชื่อเพิ่ม crateProject > Manage Crates

โครงสร้างโปรเจกต์

hello/
├── Cargo.toml      ← ชื่อโปรเจกต์ เวอร์ชัน และ crate ที่ใช้
└── src/
    └── main.rs     ← โปรแกรมเริ่มทำงานที่นี่

โปรแกรมแรก

fn main() {
    println!("สวัสดี Rust!");
}
  • fn คือการประกาศฟังก์ชัน main เป็นฟังก์ชันพิเศษ โปรแกรมเริ่มที่นี่เสมอ
  • { } ครอบสิ่งที่อยู่ในฟังก์ชัน
  • println! พิมพ์ข้อความแล้วขึ้นบรรทัดใหม่ เครื่องหมาย ! บอกว่ามันเป็น macro (ตอนนี้คิดว่าเป็นฟังก์ชันชนิดพิเศษไปก่อน)
  • ทุกคำสั่งจบด้วย ;

ใส่ค่าลงในข้อความ

fn main() {
    let name = "ไผ่";
    let age = 7;
    println!("ชื่อ {name} อายุ {age} ปี");
    println!("ปีหน้าอายุ {} ปี", age + 1);
}

เขียนชื่อตัวแปรใน { } ได้เลย หรือใช้ {} เปล่า ๆ แล้วใส่ค่าตามหลัง
