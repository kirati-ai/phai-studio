Rust Language

1. เริ่มต้นกับ Rust 2. ตัวแปร ชนิดข้อมูล ฟังก์ชัน 3. เงื่อนไขและการวนซ้ำ 4. Ownership และการยืม 5. struct, enum และ match 6. จัดการข้อผิดพลาด 7. Vec, String, HashMap 8. trait และ generic 9. โมดูล crate และเทสต์ 10. อ่าน error ของคอมไพเลอร์ 11. เธรด และก้าวต่อไป

หน้าต่างเลือกฟอนต์ (FontDialog)

ในกล่องเครื่องมือ: หน้าต่างเลือกฟอนต์ · เทียบกับ WinForms: FontDialog

หน้าต่างเลือกแบบตัวอักษรของ Windows: ชื่อฟอนต์ ขนาด ตัวหนา ตัวเอียง

  • show_dialog() ได้ Option<ChosenFont> ที่มี face, points, bold, italic

อยู่ในกล่องเครื่องมือกลุ่ม กล่องโต้ตอบ (Dialogs) - ลากมาวางแล้วมันจะไปอยู่ในแถบด้านล่างของตัวออกแบบ (ไม่ได้อยู่บนหน้าต่าง) · ในโค้ดเรียกมันว่า ui.ชื่อId ซึ่งเป็นชนิด phai_ui::ctl::FontDialog

ตัวอย่าง

1. เลือกฟอนต์แล้วบอกว่าเลือกอะไร

match กับสองค่าพร้อมกัน (bold, italic) เพื่อเขียนคำอธิบาย:

fn pick_clicked(&mut self, ui: &FontdialogDemoUi) {
    let Some(f) = ui.fonts.show_dialog() else { return };
    let style = match (f.bold, f.italic) {
        (true, true) => ", bold italic",
        (true, false) => ", bold",
        (false, true) => ", italic",
        _ => "",
    };
    ui.chosen.set_text(&format!("{}, {} pt{style}", f.face, f.points));
}

หน้าต่างตัวอย่างทั้งหมด: fontdialog_demo.phaiform กับ fontdialog_demo.rs ในโปรเจกต์ docs/help-src/examples/controls - รันด้วย cargo run -- fontdialog

Method ของ FontDialog

Methodทำอะไร
show_dialog(&self) -> Option<ChosenFont>เปิดหน้าต่าง ได้ ChosenFont (face, points, bold, italic) - None เมื่อกด Cancel
