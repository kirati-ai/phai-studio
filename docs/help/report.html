ไม่พบหน้าที่ตรงกัน

รายงานพิมพ์ (Report Designer)

ออกแบบรายงานสำหรับพิมพ์ เช่น ใบสรุปยอดขาย รายชื่อลูกค้า ใบแจ้งหนี้ โดยลากวางบนหน้ากระดาษ ดึงข้อมูลจริงจากตารางในฐานข้อมูล มีหัวกลุ่ม ผลรวม เลขหน้า ดูตัวอย่างก่อนพิมพ์ และบันทึกเป็น PDF ได้ ฟรีทุกความสามารถ

รายงานคือแถบเรียงกัน

รายงานแบ่งเป็น แถบ (band) แต่ละแถบพิมพ์ในจังหวะของมัน แล้วในแถบมีข้อความ ฟิลด์ ผลรวม เส้น กรอบ หรือรูปภาพ

แถบพิมพ์เมื่อไรมักใส่อะไร
หัวรายงาน (Report Header)ครั้งเดียวที่ต้นรายงานชื่อรายงาน โลโก้
หัวกระดาษ (Page Header)บนสุดของทุกหน้าหัวคอลัมน์
หัวกลุ่ม (Group Header)ก่อนแถวของแต่ละกลุ่มชื่อกลุ่ม เช่น "ภาค: ภาคเหนือ"
รายละเอียด (Detail)ทุกแถวของตารางฟิลด์ของแถว
ท้ายกลุ่ม (Group Footer)หลังแถวของแต่ละกลุ่มผลรวมของกลุ่ม
ท้ายรายงาน (Report Footer)ครั้งเดียวท้ายรายงานผลรวมทั้งหมด
ท้ายกระดาษ (Page Footer)ล่างสุดของทุกหน้าวันที่พิมพ์ เลขหน้า

สร้างรายงาน

  1. เปิดฟอร์มของโปรเจกต์ แล้วเลือกเมนู Project > เพิ่มรายงาน... ตั้งชื่อ เช่น SalesReport
  2. หน้าต่างตัวออกแบบรายงานเปิดขึ้น กดปุ่ม ข้อมูล... เลือกการเชื่อมต่อ ฐานข้อมูล และตาราง จาก Server Explorer (ต้องเพิ่มการเชื่อมต่อใน Server Explorer ก่อน)
  3. ถ้าแถบรายละเอียดยังว่าง ตัวออกแบบวางทุกคอลัมน์ให้ พร้อมหัวคอลัมน์ในหัวกระดาษ
  4. กด Preview ดูหน้ากระดาษจริงกับข้อมูลจริง แล้วกด บันทึก (Ctrl+S)

รายงานที่มีอยู่แล้ว ดับเบิลคลิกไฟล์ .phaireport ในหน้าต่าง Project เพื่อเปิด

หน้าต่างตัวออกแบบ

  • ซ้าย คอลัมน์ของตาราง ดับเบิลคลิกคอลัมน์ = วางฟิลด์ในแถบรายละเอียด และหัวคอลัมน์ในหัวกระดาษ
  • กลาง หน้ากระดาษ แต่ละแถบมีแถบสีบอกชื่อ ลากสิ่งของเพื่อย้าย (ลากไปปล่อยในแถบอื่นได้) ลากมุมขวาล่างเพื่อปรับขนาด ลากขอบล่างของแถบเพื่อปรับความสูง ฟิลด์แสดงเป็น [ชื่อคอลัมน์] ผลรวมแสดงเป็น sum(คอลัมน์)
  • ขวา คุณสมบัติของสิ่งที่เลือก ดับเบิลคลิกแถวเพื่อแก้ ค่าที่มีตัวเลือก (จัดแนว ฟังก์ชัน คอลัมน์) ขึ้นเป็นเมนู คลิกที่ว่างเพื่อดูคุณสมบัติของทั้งรายงาน
ปุ่มทำอะไร
ป้าย / ฟิลด์ / เส้น / กรอบ / รูปภาพเพิ่มลงแถบที่เลือกอยู่ (ไม่ได้เลือก = แถบรายละเอียด)
ผลรวมเลือกฟิลด์ก่อนแล้วกด ได้ผลรวมของคอลัมน์นั้นลงท้ายกลุ่ม (หรือท้ายรายงานถ้าไม่มีกลุ่ม) เปลี่ยนเป็นนับ เฉลี่ย ต่ำสุด สูงสุด ได้ที่คุณสมบัติ "ฟังก์ชัน"
ข้อมูล...เลือกตาราง
กลุ่ม...จัดกลุ่มตามคอลัมน์ ได้หัวกลุ่มและท้ายกลุ่มให้ หรือเอากลุ่มออก
แถบ...เปิดหรือปิดหัว/ท้ายรายงาน และหัว/ท้ายกระดาษ
Preview / พิมพ์... / PDF...ดูตัวอย่าง พิมพ์ หรือบันทึกเป็น PDF (ใช้เครื่องพิมพ์ Microsoft Print to PDF ที่มากับ Windows)

แป้นพิมพ์: Delete ลบ, ลูกศรขยับทีละนิด (Ctrl = ทีละมาก, Shift = ปรับขนาด), Ctrl+Z เลิกทำ, Ctrl+Y ทำซ้ำ

ข้อความที่เติมให้

ในป้าย (label) ใส่คำในวงเล็บปีกกา แล้วตอนพิมพ์จะถูกแทนด้วยค่าจริง

เขียนได้
{page} / {pages}หน้านี้ / จำนวนหน้าทั้งหมด เช่น หน้า {page} / {pages}
{date} {time}วันที่และเวลาที่พิมพ์
{title}ชื่อรายงาน
{row}ลำดับแถว
{ชื่อคอลัมน์}ค่าของคอลัมน์ในแถวนั้น เช่น ภาค: {region} ในหัวกลุ่ม

ตัวเลขจัดรูปแบบได้ที่คุณสมบัติ "รูปแบบ" เช่น #,##0.00 (มีจุลภาคหลักพัน ทศนิยมสองตำแหน่ง) หรือ ฿#,##0

หน้าตาด้วย CSS

เหมือนฟอร์ม หน้าตาของรายงานมาจาก CSS ค่าเริ่มต้นมีหัวรายงานตัวใหญ่ หัวคอลัมน์ตัวหนามีเส้นใต้ แถวสลับสีจาง ๆ และผลรวมตัวหนา แต่งเพิ่มได้ที่คุณสมบัติ CSS ของรายงาน:

band.group_footer   { background: #fdf6e3; }
label.report_header { color: #12855f; }
band.detail.odd     { background: #ffffff; }   /* ไม่เอาแถวสลับสี */

ชื่อชนิดคือ label field total line box และแถบคือ band โดยมี class เป็นชื่อแถบ (.page_header, .detail ...)

เรียกรายงานจากโปรแกรม

บันทึกแล้ว Phai Studio สร้างไฟล์ src/sales_report.rs ให้ (อย่าแก้ไฟล์นี้ มันถูกเขียนใหม่ทุกครั้งที่บันทึก) เรียกจากปุ่มบนฟอร์มได้เลย:

fn print_click(&mut self, ui: &MainWindowUi) {
    if let Err(e) = crate::sales_report::preview(ui.hwnd) {
        phai_ui::win::message(Some(ui.hwnd), &e, "รายงาน", Default::default());
    }
}
คำสั่งทำอะไร
sales_report::preview(hwnd)หน้าต่างดูตัวอย่าง มีปุ่มพิมพ์
sales_report::print(hwnd)หน้าต่าง Print ของ Windows แล้วพิมพ์
sales_report::export_pdf(hwnd, path)บันทึกเป็น PDF
sales_report::report()ตัวรายงาน ใส่แถวของตัวเองได้ด้วย phai_ui::report::Data::new(คอลัมน์, แถว)
รายละเอียดรูปแบบไฟล์ .phaireport อยู่ใน docs/phaireport.md ของ repo
