Rust Language

1. เริ่มต้นกับ Rust 2. ตัวแปร ชนิดข้อมูล ฟังก์ชัน 3. เงื่อนไขและการวนซ้ำ 4. Ownership และการยืม 5. struct, enum และ match 6. จัดการข้อผิดพลาด 7. Vec, String, HashMap 8. trait และ generic 9. โมดูล crate และเทสต์ 10. อ่าน error ของคอมไพเลอร์ 11. เธรด และก้าวต่อไป

รูปภาพ (PictureBox)

ในกล่องเครื่องมือ: รูปภาพ · เทียบกับ WinForms: PictureBox

แสดงรูปภาพบนหน้าต่าง จากไฟล์ PNG, JPEG, BMP หรือ GIF เช่น โลโก้ รูปสินค้า รูปประจำตัว

  • ตั้ง Image เป็นไฟล์ในโฟลเดอร์โปรเจกต์ (หรือพาธเต็ม) แล้วรูปขึ้นในตัวออกแบบทันที
  • SizeMode: zoom ใหญ่ที่สุดที่พอดีโดยไม่เบี้ยว · stretch ยืดเต็มกรอบ · center อยู่กลาง · normal ขนาดจริงชิดซ้ายบน
  • load(ไฟล์) เปลี่ยนรูปในโค้ด · event Paint วาดเองทับรูปได้

อยู่ในกล่องเครื่องมือกลุ่ม คอนโทรลทั่วไป (Common controls) - ลากมาวางบนฟอร์ม แล้วตั้ง Id (ชื่อที่ใช้ในโค้ด) ในหน้าต่าง Properties · ในโค้ดเรียกมันว่า ui.ชื่อId ซึ่งเป็นชนิด phai_ui::ctl::PictureBox

ตัวอย่าง

1. เปลี่ยนรูปด้วยโค้ด

fn loaded(&mut self, ui: &PictureDemoUi) {
    // Another picture file, found from where the program runs.
    ui.photo.load("pictures/phai.png");
}

2. คลิกแล้วเปลี่ยนวิธีวางรูป

รูปรับการคลิกได้ (event Click) - ทุกครั้งที่คลิกเปลี่ยน SizeMode ไปแบบถัดไป:

fn photo_click(&mut self, ui: &PictureDemoUi) {
    self.mode = (self.mode + 1) % MODES.len();
    ui.photo.set_size_mode(MODES[self.mode]);
    ui.mode.set_text(&format!("SizeMode: {}", MODES[self.mode]));
}

หน้าต่างตัวอย่างทั้งหมด: picture_demo.phaiform กับ picture_demo.rs ในโปรเจกต์ docs/help-src/examples/controls - รันด้วย cargo run -- picture

Events
