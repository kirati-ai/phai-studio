ไม่พบหน้าที่ตรงกัน

เว็บและมือถือ (PWA)

ฟอร์มเดิมกับโค้ดเดิมของโปรแกรม รันในเบราว์เซอร์ได้ และติดตั้งลงมือถือ Android และ iPhone เป็นแอปได้ ไม่ต้องผ่าน Play Store หรือ App Store และไม่ต้องใช้ Mac

PWA คืออะไร

PWA (Progressive Web App) คือหน้าเว็บที่ติดตั้งลงเครื่องได้เหมือนแอป ได้ไอคอนบนหน้าจอ เปิดแล้วเต็มจอ ใช้ได้แม้ไม่มีเน็ต และเมื่ออัปโหลดเวอร์ชันใหม่ขึ้นเว็บ เครื่องผู้ใช้ได้เวอร์ชันใหม่เอง

ติดตั้งเครื่องมือ (ครั้งเดียว ฟรี)

rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.130

สร้างและลองในเบราว์เซอร์

  1. เปิดฟอร์มของโปรเจกต์ใน Phai Studio
  2. Build > รันในเบราว์เซอร์ ครั้งแรกใช้เวลาสักครู่ เสร็จแล้วเบราว์เซอร์ของเครื่องนี้เปิดโปรแกรมให้
  3. หรือ Build > สร้างสำหรับเว็บ (PWA) ได้โฟลเดอร์ web/ ในโปรเจกต์ เอาไปขึ้นเว็บได้เลย

แถบสถานะบอกว่าสร้างไว้ที่ไหน และถ้าฟอร์มมี control ที่ไม่มีบนเว็บ จะบอกชื่อไว้ด้วย

รันบนมือถือระหว่างทำ (Run on Phone)

  1. ให้มือถืออยู่ใน Wi-Fi เดียวกับคอมพิวเตอร์
  2. Build > รันบนมือถือ... Phai Studio build สำหรับเว็บ แล้วขึ้นหน้าต่างมี QR code กับที่อยู่ เช่น http://192.168.1.37:8790/
  3. เปิดกล้องมือถือส่องที่ QR code (หรือพิมพ์ที่อยู่ในเบราว์เซอร์มือถือ) โปรแกรมเปิดบนมือถือเลย
  4. แก้ฟอร์มหรือโค้ดแล้วสั่ง รันบนมือถือ อีกครั้ง หน้าบนมือถือรีโหลดเอง ไม่ต้องสแกนใหม่
ครั้งแรก Windows Firewall อาจถามว่าให้ Phai Studio รับการเชื่อมต่อไหม ให้กดอนุญาตเฉพาะ เครือข่ายส่วนตัว (Private) ปุ่ม เปิดที่นี่ เปิดที่อยู่เดียวกันบนคอมพิวเตอร์ และ คัดลอกที่อยู่ ไว้ส่งต่อ
แบบนี้ใช้ลองระหว่างทำเท่านั้น เพราะเป็น http:// มือถือจะยังไม่ให้ติดตั้งเป็นแอป ถ้าจะติดตั้ง ต้องขึ้นเว็บที่เป็น HTTPS ตามหัวข้อถัดไป

ดูบนจอมือถือโดยไม่ต้องมีมือถือ (Device Preview)

View > ดูบนอุปกรณ์ (Shift+F4) แสดงฟอร์มในกรอบมือถือ มือถือจอเล็ก แท็บเล็ต หรือเดสก์ท็อป กด หมุนจอ เพื่อดูแนวนอน หรือติ๊ก มือถือ แนวนอน และแท็บเล็ต เรียงกัน เพื่อดูสามแบบพร้อมกัน แก้ฟอร์มใน designer แล้วภาพในกรอบเปลี่ยนตามเอง

ฟอร์มบนจอแคบ (PhoneLayout)

เมื่อจอแคบกว่าฟอร์มที่ออกแบบ (เช่น มือถือ) หน้าเว็บเรียง control ลงมาทีละตัว ตามลำดับการอ่าน (บนลงล่าง ซ้ายไปขวา) กว้างเต็มจอ ช่องพิมพ์และปุ่มสูงพอให้นิ้วกด แถบเครื่องมืออยู่บนสุด แถบสถานะอยู่ล่างสุด จอกว้างพอเมื่อไร ก็กลับไปวางตามที่ออกแบบ

ถ้าอยากให้ย่อทั้งฟอร์มแบบเดิมแทน ตั้ง property ของฟอร์ม PhoneLayout (หมวด Layout) เป็น zoom

ตั้งค่าแอป (ชื่อ ไอคอน สี)

Project > เว็บแอป (PWA)... ตั้งได้ว่าแอปที่ติดตั้งลงมือถือ:

ช่องความหมายถ้าเว้นว่าง
ชื่อแอปชื่อเต็มของแอปชื่อหน้าต่างของฟอร์มหลัก
ชื่อใต้ไอคอนไม่เกิน 12 ตัวอักษร (มือถือตัดที่ยาวกว่านี้)12 ตัวแรกของชื่อแอป
สีแถบด้านบน#rrggbbสีเน้น (accent) ของธีม
สีพื้นตอนเปิดแอป#rrggbbสีพื้นของธีม
แนวจอany ตามเครื่อง, portrait แนวตั้ง, landscape แนวนอนany
ไอคอนไฟล์ PNG ในโปรเจกต์ สี่เหลี่ยมจัตุรัส 512×512 ขึ้นไปสวยสุด ย่อให้เป็น 192 และ 512 เองรูปใบไผ่สีของแอป

ค่าทั้งหมดเก็บไว้ใน Cargo.toml หัวข้อ [package.metadata.phai-web] มีผลตอน build สำหรับเว็บครั้งถัดไป

แต่ง CSS เฉพาะบนเว็บ (web.css)

วางไฟล์ web.css ไว้ในโฟลเดอร์โปรเจกต์ (ข้าง Cargo.toml) แล้วเขียน CSS ได้ตรง ๆ Phai Studio ใส่ไว้ในหน้าเว็บต่อจากธีม จึงชนะค่าของธีมเสมอ เช่น

/* ทุกปุ่มบนมือถือมุมมนกว่า */
@media (max-width: 600px) {
  .phai-button { border-radius: 12px; }
}

/* ปุ่มชื่อ ok (id ของ control) */
#ok { font-weight: 600; }

/* ตอนเรียงลงมาบนจอแคบ */
.phai-stacked { gap: 14px; }

ชื่อ class ที่ใช้ได้: .phai-button, .phai-edit, .phai-label, .phai-combo, .phai-list ฯลฯ และ #ชื่อcontrol สำหรับตัวเดียว ส่วนสีและหน้าตาที่ใช้ทั้งบน Windows และเว็บ ให้แต่งใน theme.css ตาม ตกแต่งหน้าตาด้วย CSS

ขึ้นเว็บและติดตั้งลงมือถือ

Build > Publish Web App... สร้างสำหรับเว็บแล้วส่งขึ้นที่จริงให้ ใส่ปลายทางครั้งเดียว Phai Studio จำไว้ใน Cargo.toml ([package.metadata.phai-web] publish) ครั้งต่อไปกดอย่างเดียว

ปลายทางตัวอย่างทำอย่างไร
โฟลเดอร์D:\www\shopคัดลอกไฟล์ไปไว้ เช่น โฟลเดอร์ของเว็บเซิร์ฟเวอร์ หรือไดรฟ์ที่แชร์
เซิร์ฟเวอร์ (SSH)me@example.com:/var/www/shopส่งด้วย scp ของ Windows ใช้ SSH key ที่ตั้งไว้ในเครื่อง ไม่ถามรหัสผ่าน
GitHub Pagesgithub-pagesส่งไป branch gh-pages ของ repository ของโปรเจกต์ (git remote origin) แล้วเปิด https://ชื่อ.github.io/โปรเจกต์/ ให้ ครั้งแรกต้องเปิด Pages ใน Settings ของ repository บน GitHub ให้ใช้ branch gh-pages

หรือทำเอง:

  1. อัปโหลดทุกไฟล์ในโฟลเดอร์ web/ ขึ้นเว็บไซต์ที่เป็น HTTPS (เว็บของเราเอง, GitHub Pages หรืออื่น ๆ)
  2. Android: เปิดที่อยู่ใน Chrome แล้วกดเมนู ⋮ > ติดตั้งแอป หรือ เพิ่มลงหน้าจอหลัก
  3. iPhone: เปิดใน Safari กดปุ่มแชร์ > เพิ่มลงหน้าจอโฮม
ลองตัวอย่างได้ที่ phai-studio.monrak.net/demo/shop ภาษาเป็นไทยเองเมื่อเครื่องตั้งภาษาไทย หรือต่อท้ายที่อยู่ด้วย ?lang=th หรือ ?lang=en
ต้องเป็น HTTPS เท่านั้น ถ้าเปิดจาก http:// ที่ไม่ใช่เครื่องตัวเอง มือถือจะไม่ให้ติดตั้ง และใช้แบบไม่มีเน็ตไม่ได้

โค้ดไม่ต้องแก้

ไฟล์ main_window.rs ไฟล์เดียวใช้ได้ทั้ง Windows และเว็บ Phai Studio สร้างโค้ดหน้าต่างสำหรับเว็บไว้ใน src/web/ และแก้ Cargo.toml กับ main.rs ให้ครั้งแรกที่สร้างสำหรับเว็บ หลังจากนั้นโปรแกรมยัง build สำหรับ Windows ได้เหมือนเดิม

  • ตำแหน่ง control ใช้ anchor และ dock เหมือนบน Windows จอใหญ่กว่าก็ขยายตาม จอแคบกว่าที่ออกแบบ (มือถือ) เรียงลงมาทีละตัว (ดู PhoneLayout ข้างบน)
  • ฟอร์มที่สองที่เปิดด้วย show ขึ้นเป็นกล่องทับหน้า มีปุ่มปิดมุมขวาบน
  • show_dialog บนเว็บไม่รอให้ปิดก่อน ใช้ปุ่มในฟอร์มนั้นทำงานแทน

มีบนเว็บแล้ว / ยังไม่มี

มีแล้วเมนูบาร์ (เมนูย่อย ติ๊ก รายการสีเทา ปุ่มลัด Ctrl+...), toolbar (บนมือถือแสดงเป็นข้อความ), เมนูคลิกขวา (บนมือถือ: กดค้าง พร้อม Opening), tree (ลูกศรเปิดปิด ปุ่มลูกศรบนคีย์บอร์ด เหตุการณ์เมื่อเลือก และเมธอดเดียวกับ Windows), label, edit (รวมรหัสผ่าน), textarea, button, checkbox, radio, combo, listbox, checked list, list, grid, number, date, calendar, slider, progress, group, panel, tabs, link, picture, status bar, timer และ event หลักทั้งหมด (click, change, key, mouse, Shown)
ยังไม่มีsplit container, user control, dialog เลือกไฟล์ สี ฟอนต์, ErrorProvider, NotifyIcon, การพิมพ์ และ binding source

โค้ดที่เรียกสิ่งที่ยังไม่มี จะ build สำหรับเว็บไม่ผ่าน แต่ build สำหรับ Windows ได้ตามปกติ

ตารางที่ผูกฐานข้อมูล บนเว็บ

เบราว์เซอร์ต่อฐานข้อมูลตรง ๆ ไม่ได้ (และไม่ควร เพราะต้องใส่รหัสผ่านฐานข้อมูลไว้ในหน้าเว็บ) เมื่อฟอร์มมีตารางที่ผูกฐานข้อมูล Phai Studio จึงสร้าง เซิร์ฟเวอร์ข้อมูล ตัวเล็กให้ในโฟลเดอร์ data-server/ ของโปรเจกต์ มันอ่านและบันทึกเฉพาะตารางและคอลัมน์ที่ฟอร์มผูกไว้ ไม่รับคำสั่ง SQL จากหน้าเว็บ

  • ตอนทำ: Run in Browser และ Run on Phone เปิดเซิร์ฟเวอร์ข้อมูลให้เอง บนมือถือจะถาม รหัสเข้าใช้ข้อมูล ครั้งแรก (ดูได้ในแถบสถานะของ Phai Studio)
  • ใช้จริง: ที่เครื่องที่มีฐานข้อมูล เข้าโฟลเดอร์ data-server แล้ว cargo run --release ตั้ง PHAI_DB_PASSWORD (รหัสผ่านฐานข้อมูล), PHAI_DATA_TOKEN (รหัสเข้าใช้ที่แอปจะถาม ถ้าไม่ตั้ง โปรแกรมสุ่มให้แล้วแสดงออกมา - ต้องมีเสมอ เพราะเว็บอื่นที่เปิดในเบราว์เซอร์ก็เรียกเครื่องนี้ได้) และ PHAI_DATA_ADDR (ค่าเริ่มต้น 127.0.0.1:8791) แล้วให้เว็บเซิร์ฟเวอร์ที่เป็น HTTPS ส่ง /phai-data/ ต่อไปให้ เช่น nginx: location /phai-data/ { proxy_pass http://127.0.0.1:8791; }
  • เซิร์ฟเวอร์ข้อมูลอยู่คนละที่กับหน้าเว็บ: ใส่ data-url = "https://data.example.com/phai-data/" ใต้ [package.metadata.phai-web] ใน Cargo.toml
  • บนเว็บ reload_ตาราง() และ save_ตาราง() เริ่มงานแล้วกลับมาทันที ตารางเติมเมื่อข้อมูลมาถึง (มีปัญหาจะขึ้นข้อความ) ดับเบิลคลิกใต้แถวสุดท้ายเพื่อเพิ่มแถว Ctrl+Delete ลบแถวที่เลือก
