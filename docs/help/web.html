คู่มือ Phai Studio หน้าแรก

Phai Studio

ใช้งาน Phai Studio ตกแต่งหน้าตาด้วย CSS ทำงานกับฐานข้อมูล control และความสามารถเพิ่มเติม ตัวตรวจสด (F12) เว็บและมือถือ (PWA)

เรียน Rust

1. เริ่มต้นกับ Rust 2. ตัวแปร ชนิดข้อมูล ฟังก์ชัน 3. เงื่อนไขและการวนซ้ำ 4. Ownership และการยืม 5. struct, enum และ match 6. จัดการข้อผิดพลาด 7. Vec, String, HashMap 8. trait และ generic 9. โมดูล crate และเทสต์ 10. อ่าน error ของคอมไพเลอร์ 11. เธรด และก้าวต่อไป

เว็บและมือถือ (PWA)

ฟอร์มเดิมกับโค้ดเดิมของโปรแกรม รันในเบราว์เซอร์ได้ และติดตั้งลงมือถือ Android และ iPhone เป็นแอปได้ ไม่ต้องผ่าน Play Store หรือ App Store และไม่ต้องใช้ Mac

PWA คืออะไร

PWA (Progressive Web App) คือหน้าเว็บที่ติดตั้งลงเครื่องได้เหมือนแอป ได้ไอคอนบนหน้าจอ เปิดแล้วเต็มจอ ใช้ได้แม้ไม่มีเน็ต และเมื่ออัปโหลดเวอร์ชันใหม่ขึ้นเว็บ เครื่องผู้ใช้ได้เวอร์ชันใหม่เอง

ติดตั้งเครื่องมือ (ครั้งเดียว ฟรี)

rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.130

สร้างและลองในเบราว์เซอร์

  1. เปิดฟอร์มของโปรเจกต์ใน Phai Studio
  2. Build > รันในเบราว์เซอร์ ครั้งแรกใช้เวลาสักครู่ เสร็จแล้วเบราว์เซอร์ของเครื่องนี้เปิดโปรแกรมให้
  3. หรือ Build > สร้างสำหรับเว็บ (PWA) ได้โฟลเดอร์ web/ ในโปรเจกต์ เอาไปขึ้นเว็บได้เลย

แถบสถานะบอกว่าสร้างไว้ที่ไหน และถ้าฟอร์มมี control ที่ไม่มีบนเว็บ จะบอกชื่อไว้ด้วย

ขึ้นเว็บและติดตั้งลงมือถือ

  1. อัปโหลดทุกไฟล์ในโฟลเดอร์ web/ ขึ้นเว็บไซต์ที่เป็น HTTPS (เว็บของเราเอง, GitHub Pages หรืออื่น ๆ)
  2. Android: เปิดที่อยู่ใน Chrome แล้วกดเมนู ⋮ > ติดตั้งแอป หรือ เพิ่มลงหน้าจอหลัก
  3. iPhone: เปิดใน Safari กดปุ่มแชร์ > เพิ่มลงหน้าจอโฮม
ลองตัวอย่างได้ที่ phai-studio.monrak.net/demo/shop ภาษาเป็นไทยเองเมื่อเครื่องตั้งภาษาไทย หรือต่อท้ายที่อยู่ด้วย ?lang=th หรือ ?lang=en
ต้องเป็น HTTPS เท่านั้น ถ้าเปิดจาก http:// ที่ไม่ใช่เครื่องตัวเอง มือถือจะไม่ให้ติดตั้ง และใช้แบบไม่มีเน็ตไม่ได้

โค้ดไม่ต้องแก้

ไฟล์ main_window.rs ไฟล์เดียวใช้ได้ทั้ง Windows และเว็บ Phai Studio สร้างโค้ดหน้าต่างสำหรับเว็บไว้ใน src/web/ และแก้ Cargo.toml กับ main.rs ให้ครั้งแรกที่สร้างสำหรับเว็บ หลังจากนั้นโปรแกรมยัง build สำหรับ Windows ได้เหมือนเดิม

  • ตำแหน่ง control ใช้ anchor และ dock เหมือนบน Windows จอใหญ่กว่าก็ขยายตาม จอแคบกว่าที่ออกแบบ (มือถือ) ย่อทั้งหน้าให้พอดีความกว้าง
  • ฟอร์มที่สองที่เปิดด้วย show ขึ้นเป็นกล่องทับหน้า มีปุ่มปิดมุมขวาบน
  • show_dialog บนเว็บไม่รอให้ปิดก่อน ใช้ปุ่มในฟอร์มนั้นทำงานแทน

มีบนเว็บแล้ว / ยังไม่มี

มีแล้วlabel, edit (รวมรหัสผ่าน), textarea, button, checkbox, radio, combo, listbox, checked list, list, grid, number, date, calendar, slider, progress, group, panel, tabs, link, picture, status bar, timer และ event หลักทั้งหมด (click, change, key, mouse, Shown)
ยังไม่มีเมนูบาร์, toolbar, เมนูคลิกขวา, tree, split container, user control, dialog เลือกไฟล์ สี ฟอนต์, ErrorProvider, NotifyIcon, การพิมพ์, binding source และตารางที่ผูกฐานข้อมูล

โค้ดที่เรียกสิ่งที่ยังไม่มี จะ build สำหรับเว็บไม่ผ่าน แต่ build สำหรับ Windows ได้ตามปกติ
