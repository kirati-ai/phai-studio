Rust Language

1. เริ่มต้นกับ Rust 2. ตัวแปร ชนิดข้อมูล ฟังก์ชัน 3. เงื่อนไขและการวนซ้ำ 4. Ownership และการยืม 5. struct, enum และ match 6. จัดการข้อผิดพลาด 7. Vec, String, HashMap 8. trait และ generic 9. โมดูล crate และเทสต์ 10. อ่าน error ของคอมไพเลอร์ 11. เธรด และก้าวต่อไป

ตัวตรวจสด (F12)

ระหว่างรันโปรแกรมแบบ debug กด F12 ในหน้าต่างโปรแกรม จะได้ตัวตรวจสดข้างหน้าต่าง ปรับหน้าตา control ดูผลทันที แล้วเก็บลงฟอร์มได้ เหมือน DevTools ของเบราว์เซอร์

เปิดตัวตรวจ

  1. กด F5 ใน Phai Studio เพื่อรันโปรแกรม
  2. ในหน้าต่างโปรแกรม กด F12 (หรือ Ctrl+Shift+I) ตัวตรวจเปิดข้างหน้าต่าง
  3. กด ชี้เลือก แล้วคลิก control ในหน้าต่าง กรอบสีฟ้าบอกว่าเลือกตัวไหน กด Esc เพื่อเลิกชี้ หรือเลือกจากรายการก็ได้

ปรับอะไรได้

  • หน้าตาทีละสถานะ ปกติ, hover, pressed, focus, disabled, checked: สีพื้น สีตัวอักษร สีเส้นขอบ มุมมน ความหนาเส้น ตัวหนา gradient เงา พิมพ์แล้ว control ในโปรแกรมเปลี่ยนทันที
  • แต่ละค่าบอกว่ามาจากไหน เช่น own :hover (ของ control เอง) หรือ button.primary:hover · phai:light (จากธีม)
  • ข้อความ ใช้งานได้ มองเห็น และ property อื่น เช่น tooltip, read only

เก็บลงฟอร์ม

  • เก็บลงฟอร์ม เขียนเฉพาะบรรทัดของ control นั้นในไฟล์ .phaiform คอมเมนต์และบรรทัดอื่นอยู่เหมือนเดิม
  • สลับกลับมาที่ Phai Studio ฟอร์มที่เปิดอยู่โหลดใหม่ให้เอง และ Undo ได้
  • ย้อนทั้งหมด คืนทุกอย่างกลับเป็นตอนเปิดตัวตรวจ
ตัวตรวจมีเฉพาะโปรแกรมที่ build แบบ debug เท่านั้น โปรแกรมที่ build แบบ release เพื่อแจกจ่ายไม่มีตัวตรวจ และไม่มีโค้ดส่วนนี้ติดไปด้วย
รันโปรเจกต์แรก กด F12 ชี้ที่ปุ่ม OK เลือกสถานะ hover แล้วเปลี่ยนสีพื้นเป็น #2563eb เอาเมาส์ไปชี้ปุ่มดู แล้วกดเก็บลงฟอร์ม
