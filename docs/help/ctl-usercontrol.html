User control (UserControl)

ในกล่องเครื่องมือ: User control (control ของโปรเจกต์) · เทียบกับ WinForms: UserControl

control ที่เราสร้างเองจาก control อื่น ๆ แล้วใช้ซ้ำได้หลายที่ เช่น กล่องนับจำนวน กล่องที่อยู่ แถบค้นหา - ออกแบบครั้งเดียว วางกี่ที่ก็ได้

  • สร้าง: Project > Add User Control... ได้ฟอร์มที่มี user_control = true ออกแบบเหมือนฟอร์มทั่วไป
  • ใช้: ลาก User control จากกล่องเครื่องมือมาวาง แล้วตั้ง Type เป็นชื่อของมัน (เช่น CounterBox)
  • มันบอกฟอร์มว่ามีอะไรเปลี่ยนด้วย ui.notify_parent() - ฟอร์มได้ยินทาง …_changed
  • ฟอร์มอ่าน control ข้างในมันด้วย CounterBoxUi::with(ui.ชื่อ, |c| …)

อยู่ในกล่องเครื่องมือกลุ่ม ตัวบรรจุ (Containers) - ลากมาวางบนฟอร์ม แล้วตั้ง Id (ชื่อที่ใช้ในโค้ด) ในหน้าต่าง Properties · ในโค้ดเรียกมันว่า ui.ชื่อId ซึ่งเป็นชนิด phai_ui::ctl::UserControl

ตัวอย่าง

1. สร้าง user control

counter_box.phaiform มีปุ่ม -, ป้ายตัวเลข, ปุ่ม + (สังเกต user_control = true) และโค้ดของมัน:

# Phai Studio form - docs/phaiform.md
format = 1

[form]
name = "CounterBox"
title = "CounterBox"
size = [200, 40]
user_control = true

[[control]]
kind = "button"
id = "minus"
text = "-"
bounds = [0, 4, 40, 30]
on_click = "minus_clicked"

[[control]]
kind = "label"
id = "value"
text = "0"
bounds = [48, 8, 100, 24]
text_align = "center"

[[control]]
kind = "button"
id = "plus"
text = "+"
bounds = [156, 4, 40, 30]
on_click = "plus_clicked"
#[derive(Default)]
pub struct CounterBox {
    n: i32,
}

impl CounterBoxEvents for CounterBox {
    fn minus_clicked(&mut self, ui: &CounterBoxUi) {
        self.n -= 1;
        ui.value.set_text(&self.n.to_string());
        ui.notify_parent(); // the form's on_change for it runs
    }

    fn plus_clicked(&mut self, ui: &CounterBoxUi) {
        self.n += 1;
        ui.value.set_text(&self.n.to_string());
        ui.notify_parent();
    }
}

2. วางสองตัวบนหน้าต่าง แล้วรวมค่า

ทั้งสองตัวใช้ count_changed - อ่านตัวเลขจากแต่ละตัวด้วย CounterBoxUi::with:

fn count_changed(&mut self, ui: &UsercontrolDemoUi) {
    // CounterBoxUi::with gives a CounterBox's own controls.
    let read = |h| CounterBoxUi::with(h, |c| c.value.text().parse::<i32>().unwrap_or(0)).unwrap_or(0);
    let people = read(ui.adults) + read(ui.children);
    ui.total.set_text(&format!("{people} people"));
}

หน้าต่างตัวอย่างทั้งหมด: usercontrol_demo.phaiform กับ usercontrol_demo.rs ในโปรเจกต์ docs/help-src/examples/controls - รันด้วย cargo run -- usercontrol

Events

ดับเบิลคลิกชื่อ event ในแท็บ Events ของ Properties แล้ว Phai Studio จะเขียน method ให้ (ชื่อในตารางนี้สมมติว่า Id ของมันคือ usercontrol และอยู่บนฟอร์ม MainWindow) - ชี้เมาส์ที่ชนิดของ e เพื่อดูชื่อเต็ม
