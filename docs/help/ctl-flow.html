จัดเรียงต่อกัน (FlowLayoutPanel)

ในกล่องเครื่องมือ: จัดเรียงต่อกัน (Flow) · เทียบกับ WinForms: FlowLayoutPanel

แผงที่เรียง control ต่อกันเอง จากซ้ายไปขวา เต็มบรรทัดแล้วขึ้นบรรทัดใหม่ เหมือนตัวหนังสือ ไม่ต้องจัดตำแหน่งทีละตัว

  • วาง control ลงข้างในแผง แล้วแผงจะจัดตำแหน่งให้ตามลำดับในฟอร์ม
  • FlowDirection เรียงไปทางไหน · WrapContents ขึ้นบรรทัดใหม่เมื่อเต็มไหม · Padding ระยะจากขอบ
  • ซ่อน control ตัวหนึ่ง ตัวอื่นจะขยับมาปิดช่องว่างเอง

อยู่ในกล่องเครื่องมือกลุ่ม ตัวบรรจุ (Containers) - ลากมาวางบนฟอร์ม แล้วตั้ง Id (ชื่อที่ใช้ในโค้ด) ในหน้าต่าง Properties · ในโค้ดเรียกมันว่า ui.ชื่อId ซึ่งเป็นชนิด phai_ui::ctl::FlowPanel

1. วางในแผงตอนออกแบบ

control สี่ตัวที่อยู่ในกรอบของ tags ถูกแผงจัดเรียงให้ (ตำแหน่งที่เขียนไว้ใช้แค่บอกว่าอยู่ในแผงไหน):

2. ซ่อนแล้วตัวอื่นขยับมา

fn hide_green_clicked(&mut self, ui: &FlowDemoUi) {
    // The panel lays its controls out again: the others move up into the gap.
    let showing = ui.green.visible();
    ui.green.set_visible(!showing);
    ui.hide_green.set_text(if showing { "Show green" } else { "Hide green" });
}

Events

ดับเบิลคลิกชื่อ event ในแท็บ Events ของ Properties แล้ว Phai Studio จะเขียน method ให้ (ชื่อในตารางนี้สมมติว่า Id ของมันคือ flow และอยู่บนฟอร์ม MainWindow) - ชี้เมาส์ที่ชนิดของ e เพื่อดูชื่อเต็ม

Eventทำอะไรmethod ที่ Phai Studio เขียนให้

MouseEnterเมาส์เลื่อนเข้ามาบนตัวนี้fn flow_mouse_enter(&mut self, ui: &MainWindowUi)

MouseUpปล่อยปุ่มเมาส์บนตัวนี้fn flow_mouse_up(&mut self, ui: &MainWindowUi, e: &MouseEventArgs)
