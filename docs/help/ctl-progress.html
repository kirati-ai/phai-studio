แถบความคืบหน้า (ProgressBar)

ในกล่องเครื่องมือ: แถบความคืบหน้า · เทียบกับ WinForms: ProgressBar

แถบที่บอกว่างานทำไปได้แค่ไหนแล้ว เช่น ดาวน์โหลด คัดลอกไฟล์ ติดตั้ง ผู้ใช้จะได้รู้ว่าโปรแกรมไม่ได้ค้าง

  • Minimum / Maximum (มักเป็น 0 ถึง 100) · Value ตอนนี้อยู่ที่เท่าไหร่ · Step ขยับครั้งละเท่าไหร่
  • งานที่ไม่รู้ว่านานเท่าไหร่ ตั้ง Style = Marquee ให้มีแถบวิ่งไปเรื่อย ๆ (หรือ set_marquee(true))

อยู่ในกล่องเครื่องมือกลุ่ม คอนโทรลทั่วไป (Common controls) - ลากมาวางบนฟอร์ม แล้วตั้ง Id (ชื่อที่ใช้ในโค้ด) ในหน้าต่าง Properties · ในโค้ดเรียกมันว่า ui.ชื่อId ซึ่งเป็นชนิด phai_ui::ctl::ProgressBar

ตัวอย่าง

1. ขยับทีละขั้น

perform_step() บวกเพิ่มตาม Step:

fn next_clicked(&mut self, ui: &ProgressDemoUi) {
    ui.work.perform_step(); // adds Step (10)
    let v = ui.work.value();
    ui.done.set_text(&format!("{v}% done"));
    if v >= 100 {
        ui.next.set_enabled(false);
    }
}

2. เริ่มใหม่

fn again_clicked(&mut self, ui: &ProgressDemoUi) {
    ui.work.set_value(0);
    ui.done.set_text("");
    ui.next.set_enabled(true);
}

หน้าต่างตัวอย่างทั้งหมด: progress_demo.phaiform กับ progress_demo.rs ในโปรเจกต์ docs/help-src/examples/controls - รันด้วย cargo run -- progress

Events

ดับเบิลคลิกชื่อ event ในแท็บ Events ของ Properties แล้ว Phai Studio จะเขียน method ให้ (ชื่อในตารางนี้สมมติว่า Id ของมันคือ progress และอยู่บนฟอร์ม MainWindow) - ชี้เมาส์ที่ชนิดของ e เพื่อดูชื่อเต็ม

Eventทำอะไรmethod ที่ Phai Studio เขียนให้

DoubleClickถูกดับเบิลคลิกfn progress_double_click(&mut self, ui: &MainWindowUi)
MouseEnterเมาส์เลื่อนเข้ามาบนตัวนี้fn progress_mouse_enter(&mut self, ui: &MainWindowUi)
MouseLeaveเมาส์เลื่อนออกจากตัวนี้fn progress_mouse_leave(&mut self, ui: &MainWindowUi)

MouseUpปล่อยปุ่มเมาส์บนตัวนี้fn progress_mouse_up(&mut self, ui: &MainWindowUi, e: &MouseEventArgs)
