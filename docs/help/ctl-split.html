แบ่งสองช่อง (SplitContainer)

ในกล่องเครื่องมือ: แบ่งสองช่อง · เทียบกับ WinForms: SplitContainer

แบ่งพื้นที่เป็นสองช่องซ้าย-ขวา (หรือบน-ล่าง) มีแถบตรงกลางที่ผู้ใช้ลากปรับขนาดได้ เหมือน Explorer ที่มีรายการโฟลเดอร์ทางซ้ายและไฟล์ทางขวา

  • มักตั้ง Dock = fill ให้เต็มหน้าต่าง · Orientation แนวตั้งหรือแนวนอน · SplitterDistance ความกว้างของช่องแรก
  • วาง control ลงในช่องซ้ายหรือขวาในตัวออกแบบ
  • ดับเบิลคลิกในตัวออกแบบ ได้ method ตอนแถบถูกลาก (…_changed)

อยู่ในกล่องเครื่องมือกลุ่ม ตัวบรรจุ (Containers) - ลากมาวางบนฟอร์ม แล้วตั้ง Id (ชื่อที่ใช้ในโค้ด) ในหน้าต่าง Properties · ในโค้ดเรียกมันว่า ui.ชื่อId ซึ่งเป็นชนิด phai_ui::ctl::SplitContainer

ตัวอย่าง

1. รู้ว่าแถบอยู่ตรงไหน

fn halves_changed(&mut self, ui: &SplitDemoUi) {
    // The bar was dragged: how wide the left pane is now.
    ui.width.set_text(&format!("Left pane: {} px - drag the bar", ui.halves.splitter_distance()));
}

หน้าต่างตัวอย่างทั้งหมด: split_demo.phf กับ split_demo.rs ในโปรเจกต์ docs/help-src/examples/controls - รันด้วย cargo run -- split

Events

ดับเบิลคลิกชื่อ event ในแท็บ Events ของ Properties แล้ว Phai Studio จะเขียน method ให้ (ชื่อในตารางนี้สมมติว่า Id ของมันคือ split และอยู่บนฟอร์ม MainWindow) - ชี้เมาส์ที่ชนิดของ e เพื่อดูชื่อเต็ม

Eventทำอะไรmethod ที่ Phai Studio เขียนให้
เปลี่ยนเมธอดที่ทำงานเมื่อเกิดเหตุการณ์นี้ ดับเบิลคลิก control เพื่อเขียนfn split_changed(&mut self, ui: &MainWindowUi)
DoubleClickถูกดับเบิลคลิกfn split_double_click(&mut self, ui: &MainWindowUi)
MouseEnterเมาส์เลื่อนเข้ามาบนตัวนี้fn split_mouse_enter(&mut self, ui: &MainWindowUi)
MouseLeaveเมาส์เลื่อนออกจากตัวนี้fn split_mouse_leave(&mut self, ui: &MainWindowUi)
MouseDownกดปุ่มเมาส์บนตัวนี้ - e.x, e.y, e.buttonfn split_mouse_down(&mut self, ui: &MainWindowUi, e: &MouseEventArgs)
MouseUpปล่อยปุ่มเมาส์บนตัวนี้fn split_mouse_up(&mut self, ui: &MainWindowUi, e: &MouseEventArgs)
MouseMoveเมาส์เคลื่อนบนตัวนี้fn split_mouse_move(&mut self, ui: &MainWindowUi, e: &MouseEventArgs)
MouseWheelหมุนลูกล้อเมาส์บน control - e.delta ทีละ 120 ต่อหนึ่งจังหวะ มากกว่า 0 คือหมุนออกจากตัวfn split_mouse_wheel(&mut self, ui: &MainWindowUi, e: &MouseEventArgs)
Resizeขนาดเปลี่ยน - หน้าต่างถูกย่อขยายและตัวนี้ยึดขอบหรือ dock ไว้fn split_resize(&mut self, ui: &MainWindowUi)
DragDropมีของถูกวางลงมา: ไฟล์จาก Explorer (e.files) หรือข้อความที่ลากมาจาก control อื่น (e.text, e.source)fn split_drag_drop(&mut self, ui: &MainWindowUi, e: &FileDropEventArgs)
