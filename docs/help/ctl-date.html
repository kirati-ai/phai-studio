วันที่ (DateTimePicker)

ในกล่องเครื่องมือ: วันที่ · เทียบกับ WinForms: DateTimePicker

ช่องสำหรับเลือกวันที่ กดลูกศรแล้วมีปฏิทินให้เลือก ผู้ใช้ไม่ต้องพิมพ์วันที่เอง จึงไม่มีรูปแบบผิด

  • value() ได้ (ปี, เดือน, วัน) เป็นตัวเลขสามตัว
  • Format และ CustomFormat กำหนดว่าวันที่แสดงหน้าตาแบบไหน
  • MinDate / MaxDate จำกัดช่วงวันที่ที่เลือกได้ · ShowCheckBox ให้ผู้ใช้เลือกว่า "ไม่ระบุวันที่" ได้

อยู่ในกล่องเครื่องมือกลุ่ม คอนโทรลทั่วไป (Common controls) - ลากมาวางบนฟอร์ม แล้วตั้ง Id (ชื่อที่ใช้ในโค้ด) ในหน้าต่าง Properties · ในโค้ดเรียกมันว่า ui.ชื่อId ซึ่งเป็นชนิด phai_ui::ctl::DateTimePicker

ตัวอย่าง

1. ตั้งวันที่ตอนเปิดหน้าต่าง

set_value(ปี, เดือน, วัน):

fn loaded(&mut self, ui: &DateDemoUi) {
    ui.birthday.set_value(2015, 6, 1); // year, month, day
    self.birthday_changed(ui);
}

2. อ่านวันที่ที่เลือก

ทุกครั้งที่เลือกวันใหม่ method …_changed ทำงาน:

fn birthday_changed(&mut self, ui: &DateDemoUi) {
    let (year, month, day) = ui.birthday.value();
    ui.shown.set_text(&format!("Born on {day}/{month}/{year}"));
}

หน้าต่างตัวอย่างทั้งหมด: date_demo.phaiform กับ date_demo.rs ในโปรเจกต์ docs/help-src/examples/controls - รันด้วย cargo run -- date

Events

ดับเบิลคลิกชื่อ event ในแท็บ Events ของ Properties แล้ว Phai Studio จะเขียน method ให้ (ชื่อในตารางนี้สมมติว่า Id ของมันคือ date และอยู่บนฟอร์ม MainWindow) - ชี้เมาส์ที่ชนิดของ e เพื่อดูชื่อเต็ม

Eventทำอะไรmethod ที่ Phai Studio เขียนให้
เปลี่ยนเมธอดที่ทำงานเมื่อเกิดเหตุการณ์นี้ ดับเบิลคลิก control เพื่อเขียนfn date_changed(&mut self, ui: &MainWindowUi)
DoubleClickถูกดับเบิลคลิกfn date_double_click(&mut self, ui: &MainWindowUi)
Enterได้รับโฟกัส แป้นที่กดต่อไปจะเข้าตัวนี้fn date_enter(&mut self, ui: &MainWindowUi)
Leaveโฟกัสย้ายไปที่อื่นfn date_leave(&mut self, ui: &MainWindowUi)
KeyDownกดแป้นขณะมีโฟกัส - e.key, e.ctrl; เรียก e.set_handled() เพื่อไม่ให้ control ได้รับแป้นนั้นfn date_key_down(&mut self, ui: &MainWindowUi, e: &KeyEventArgs)
KeyUpปล่อยแป้นขณะมีโฟกัสfn date_key_up(&mut self, ui: &MainWindowUi, e: &KeyEventArgs)
KeyPressพิมพ์ตัวอักษร - e.ch; เรียก e.set_handled() เพื่อไม่ให้ตัวอักษรเข้าไปfn date_key_press(&mut self, ui: &MainWindowUi, e: &KeyPressEventArgs)
MouseEnterเมาส์เลื่อนเข้ามาบนตัวนี้fn date_mouse_enter(&mut self, ui: &MainWindowUi)
MouseLeaveเมาส์เลื่อนออกจากตัวนี้fn date_mouse_leave(&mut self, ui: &MainWindowUi)

MouseUpปล่อยปุ่มเมาส์บนตัวนี้fn date_mouse_up(&mut self, ui: &MainWindowUi, e: &MouseEventArgs)
