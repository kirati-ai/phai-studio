เรียน Rust

1. เริ่มต้นกับ Rust 2. ตัวแปร ชนิดข้อมูล ฟังก์ชัน 3. เงื่อนไขและการวนซ้ำ 4. Ownership และการยืม 5. struct, enum และ match 6. จัดการข้อผิดพลาด 7. Vec, String, HashMap 8. trait และ generic 9. โมดูล crate และเทสต์ 10. อ่าน error ของคอมไพเลอร์ 11. เธรด และก้าวต่อไป

9. โมดูล crate และเทสต์

จัดโค้ดให้เป็นระเบียบ ใช้ไลบรารีของคนอื่น และพิสูจน์ว่าโค้ดถูก

แยกโค้ดเป็นหลายไฟล์ด้วย mod

src/
├── main.rs
├── shop.rs        ← โมดูล shop
└── report.rs      ← โมดูล report
// main.rs
mod shop;           // บอกว่ามีไฟล์ shop.rs
mod report;

use shop::Product;  // ดึงชื่อมาใช้สั้น ๆ

fn main() {
    let p = Product::new("กาแฟ", 45.0);
    report::print(&p);
}
// shop.rs
pub struct Product {       // pub = ไฟล์อื่นมองเห็น
    pub name: String,
    pub price: f64,
}

impl Product {
    pub fn new(name: &str, price: f64) -> Product {
        Product { name: name.into(), price }
    }
}
// report.rs
use crate::shop::Product;  // crate:: = เริ่มจากรากของโปรเจกต์

pub fn print(p: &Product) {
    println!("{} ราคา {}", p.name, p.price);
}

ทุกอย่างเป็น ส่วนตัวโดยค่าเริ่มต้น ต้องใส่ pub ถึงจะใช้จากไฟล์อื่นได้

ใช้ crate จาก crates.io

ใน Phai Studio เปิด Project > Manage Crates ค้นหา แล้วกด Add (เท่ากับ cargo add ชื่อ) Cargo จะเพิ่มบรรทัดใน Cargo.toml:

[dependencies]
rand = "0.8"
serde = { version = "1", features = ["derive"] }
use rand::Rng;

fn main() {
    let n = rand::thread_rng().gen_range(1..=6);
    println!("ทอยได้ {n}");
}
ก่อนใช้ crate ไหน ดูที่ crates.io ว่ามีคนดาวน์โหลดเยอะไหม อัปเดตล่าสุดเมื่อไร และอ่านตัวอย่างในหน้าเอกสาร (docs.rs)

เขียนเทสต์

เทสต์คือโค้ดที่ตรวจว่าโค้ดของเราทำงานถูก เขียนไว้ในไฟล์เดียวกันได้เลย:

pub fn vat(price: f64) -> f64 {
    price * 0.07
}

pub fn grade(score: u32) -> char {
    match score {
        80..=100 => 'A',
        70..=79 => 'B',
        60..=69 => 'C',
        50..=59 => 'D',
        _ => 'F',
    }
}

#[cfg(test)]            // คอมไพล์เฉพาะตอนรันเทสต์
mod tests {
    use super::*;       // ใช้ทุกอย่างจากไฟล์ข้างบน

    #[test]
    fn vat_is_seven_percent() {
        assert_eq!(vat(100.0), 7.0);
    }

    #[test]
    fn grades_follow_the_ranges() {
        assert_eq!(grade(85), 'A');
        assert_eq!(grade(50), 'D');
        assert_eq!(grade(10), 'F');
    }

    #[test]
    #[should_panic]
    fn reading_past_the_end_panics() {
        let v: Vec<i32> = vec![];
        let _ = v[0];
    }
}
macroตรวจอะไร
assert!(x)x เป็นจริง
assert_eq!(a, b)a == b ถ้าไม่เท่าจะแสดงทั้งสองค่า
assert_ne!(a, b)a != b

ใน Phai Studio กด Ctrl+R, T ผลแต่ละเทสต์ขึ้นในแท็บ Tests ดับเบิลคลิกเทสต์ที่ไม่ผ่านเพื่อไปที่โค้ด และใช้ Test > Analyze Code Coverage ดูว่าบรรทัดไหนยังไม่มีเทสต์ไปถึง (แถบแดงที่ขอบซ้าย)

เพิ่มเทสต์ให้ฟังก์ชันที่คุณเขียนในบทก่อน ๆ อย่างน้อยฟังก์ชันละ 2 เทสต์ ลองทำให้เทสต์หนึ่งไม่ผ่านโดยตั้งใจ แล้วดูว่า Phai Studio แสดงผลอย่างไร
