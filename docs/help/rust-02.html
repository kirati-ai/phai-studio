2. ตัวแปร ชนิดข้อมูล ฟังก์ชัน

พื้นฐานที่ทุกโปรแกรมต้องใช้

ตัวแปรด้วย let

let price = 120;
println!("{price}");

ใน Rust ตัวแปรแก้ไม่ได้โดยค่าเริ่มต้น ถ้าต้องการแก้ ต้องบอกด้วย mut (มาจาก mutable)

let mut count = 0;
count = count + 1;   // ได้ เพราะมี mut
count += 1;          // แบบย่อ

let total = 10;
total = 20;          // error: cannot assign twice to immutable variable
ทำไมต้องแก้ไม่ได้? เพราะส่วนใหญ่ค่าไม่ได้เปลี่ยน การบังคับให้เขียน mut ทำให้คนอ่านโค้ดรู้ทันทีว่าตัวแปรไหนจะเปลี่ยนค่า และคอมไพเลอร์ช่วยจับได้ถ้าเผลอแก้

Shadowing: ประกาศชื่อเดิมซ้ำ

let input = "42";
let input: i32 = input.parse().unwrap();  // ชื่อเดิม แต่เป็นตัวแปรใหม่ ชนิดใหม่
println!("{}", input + 1);  // 43

ชนิดข้อมูลพื้นฐาน

ชนิดเก็บอะไรตัวอย่าง
i32จำนวนเต็ม (บวกหรือลบ) ใช้บ่อยที่สุด-5, 2024
i64, u8, u32, u64จำนวนเต็มขนาดอื่น u = ไม่ติดลบ255u8
usizeจำนวนเต็มที่ใช้นับตำแหน่งและขนาดlist.len()
f64ทศนิยม3.14
boolจริง/เท็จtrue, false
charตัวอักษรหนึ่งตัว (ใส่ ' ')'ก', 'A'
&strข้อความที่อ่านอย่างเดียว (ใส่ " ")"สวัสดี"
Stringข้อความที่แก้ไขและเพิ่มได้String::from("ไผ่")

ส่วนใหญ่ไม่ต้องบอกชนิด Rust เดาให้จากค่า แต่จะบอกเองก็ได้ด้วย :

let a = 5;          // Rust รู้ว่าเป็น i32
let b: f64 = 5.0;   // บอกเอง
let c = 10 / 3;     // 3  (จำนวนเต็มหารกันได้จำนวนเต็ม)
let d = 10.0 / 3.0; // 3.3333333333333335
Rust ไม่แปลงชนิดให้อัตโนมัติ 5 + 2.0 คือ error ต้องแปลงเองด้วย as เช่น 5 as f64 + 2.0

Tuple และ array

let point = (10, 20);            // tuple: หลายค่า ต่างชนิดกันได้
println!("x = {}", point.0);

let days = ["จ", "อ", "พ"];        // array: ชนิดเดียวกัน จำนวนคงที่
println!("{}", days[0]);          // "จ"
println!("มี {} วัน", days.len());

ฟังก์ชัน

fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn greet(name: &str) {
    println!("สวัสดี {name}");
}

fn main() {
    let sum = add(3, 4);
    greet("ไผ่");
    println!("{sum}");
}
  • พารามิเตอร์ต้องบอกชนิดเสมอ
  • -> i32 บอกชนิดของค่าที่คืน ถ้าไม่คืนอะไรก็ไม่ต้องเขียน
  • บรรทัดสุดท้ายที่ไม่มี ; คือค่าที่คืน (เขียน return a + b; ก็ได้ แต่คนเขียน Rust นิยมแบบไม่มี ;)
เผลอใส่ ; หลัง a + b จะได้ error "mismatched types" เพราะบรรทัดนั้นกลายเป็นคำสั่ง ไม่คืนค่าแล้ว

Block ก็มีค่า

let grade = {
    let score = 75;
    if score >= 50 { "ผ่าน" } else { "ไม่ผ่าน" }
};
เขียนฟังก์ชัน fn area(width: f64, height: f64) -> f64 คืนพื้นที่สี่เหลี่ยม แล้วพิมพ์พื้นที่ของห้องขนาด 3.5 × 4 เมตร จากนั้นเขียน fn celsius_to_f(c: f64) -> f64 (สูตร c × 9 / 5 + 32)
