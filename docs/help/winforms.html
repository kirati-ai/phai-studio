คู่มือ Phai Studio หน้าแรก

Phai Studio

ใช้งาน Phai Studio ตกแต่งหน้าตาด้วย CSS ทำงานกับฐานข้อมูล control และความสามารถเพิ่มเติม ตัวตรวจสด (F12) เว็บและมือถือ (PWA)

เรียน Rust

1. เริ่มต้นกับ Rust 2. ตัวแปร ชนิดข้อมูล ฟังก์ชัน 3. เงื่อนไขและการวนซ้ำ 4. Ownership และการยืม 5. struct, enum และ match 6. จัดการข้อผิดพลาด 7. Vec, String, HashMap 8. trait และ generic 9. โมดูล crate และเทสต์ 10. อ่าน error ของคอมไพเลอร์ 11. เธรด และก้าวต่อไป

control และความสามารถเพิ่มเติม

นอกจาก control พื้นฐาน Phai Studio มี control และความสามารถแบบ WinForms ครบชุด ทุกอย่างวางจากกล่องเครื่องมือ ตั้งค่าในหน้าต่าง Properties แล้วเรียกจากโค้ดผ่าน ui.ชื่อ เหมือน control อื่น

control เพิ่มเติม

controlใช้ทำอะไรเรียกจากโค้ด
Panelกล่องรวม control มีสีพื้นของตัวเอง หรือเส้นขอบ (border = "fixed")ลาก control อื่นใส่ข้างในได้
Split containerสองช่องกับเส้นแบ่งที่ลากได้ control ในแต่ละช่องยึด anchor กับช่องของตัวเองsplitter_distance(), set_splitter_distance(200)
ListBoxรายการให้เลือกหนึ่งหรือหลายบรรทัด (selection_mode = "multi")items_add("..."), selected_index(), selected_indices()
CheckedListBoxรายการที่แต่ละบรรทัดมีช่องติ๊กchecked(i), set_checked(i, true), checked_indices()
LinkLabelข้อความที่เป็นลิงก์ กดแล้วเรียก on_clickset_link_text("...")
MaskedTextBoxช่องที่รับเฉพาะรูปแบบที่กำหนด เช่น เบอร์โทร mask = "000-000-0000"value() (ไม่รวมขีด), mask_completed()
MonthCalendarปฏิทินให้เลือกวัน สีตามธีมselection_start(), set_date(2026, 11, 20)

ตัวอักษรใน mask: 0 ตัวเลข, 9 ตัวเลขหรือเว้นว่าง, L ตัวอักษร, A ตัวอักษรหรือตัวเลข, \ ใส่ตัวถัดไปตามที่เขียน

component (ไม่มีหน้าตาบนฟอร์ม)

component วางแล้วไปอยู่แถบด้านล่างฟอร์ม เหมือน Visual Studio

componentใช้ทำอะไร
Open / Save file dialogหน้าต่างเลือกไฟล์ของ Windows ตั้ง title, filter (ไฟล์ข้อความ|*.txt|ทุกไฟล์|*.*), default_ext แล้วเรียก ui.open_file.show_dialog() ได้ Option<PathBuf>
Folder / Color / Font dialogเลือกโฟลเดอร์, สี (show_dialog("#12855f") ได้ #rrggbb), ฟอนต์ (ได้ชื่อ ขนาด ตัวหนา ตัวเอียง)
ErrorProviderเครื่องหมายแดงข้าง control ที่กรอกผิด: ui.errors.set_error(ui.name, "ใส่ชื่อด้วย") ส่งข้อความว่างเพื่อลบ
NotifyIconไอคอนมุมขวาล่างของ taskbar มี on_click, double_click, เมนูคลิกขวา (context_menu) และ show_balloon_tip(...)
Timerเรียก on_tick ทุกกี่มิลลิวินาทีตามที่ตั้ง

เมนูแบบละเอียด

ในหน้าต่างแก้เมนู เขียนเมนูเป็นบรรทัด ย่อหน้าเข้าไปคือเมนูย่อย ชื่ออย่างเดียวในบรรทัดคือหัวเมนูย่อย:

&View
  word_wrap | Word wrap | checked | check_on_click
  Zoom
    zoom_in | Zoom in | Ctrl+= | SEARCH
    zoom_max | Most | disabled
  • checked ติ๊กไว้ตั้งแต่เปิด, check_on_click กดแล้วสลับติ๊กเอง, disabled สีเทากดไม่ได้, ชื่อไอคอน (เช่น SEARCH) แสดงหน้าเมนู
  • ปุ่ม toolbar ที่เขียน | toggle เป็นปุ่มกดค้าง และติ๊กพร้อมกับเมนูที่ id เดียวกัน
  • จากโค้ด: ui.item_checked("word_wrap"), ui.set_item_checked("word_wrap", true), ui.set_item_enabled("zoom_max", false)

ฟอร์มซ้อนในฟอร์ม (MDI)

ตั้ง IsMdiContainer ของฟอร์มหลัก แล้วเปิดฟอร์มอื่นข้างในด้วย EditorUi::show_mdi_child(ui.hwnd, editor::Editor::default()) จัดเรียงด้วย ui.layout_mdi("cascade") (หรือ tile_horizontal, tile_vertical) ใช้ Ctrl+Tab สลับ และ Ctrl+F4 ปิดฟอร์มลูก

ลากข้อความจาก control หนึ่งไปวางอีกตัว

ใน event MouseDown ของ control ต้นทาง เรียก ui.list.do_drag_drop("ข้อความ") ป้ายเล็ก ๆ จะตามเมาส์ไป control ปลายทางที่มี event DragDrop ได้ e.text และ e.source กด Esc เพื่อยกเลิก ไฟล์ที่ลากมาจาก Explorer เข้า e.files

การพิมพ์

วาง component Print document ตั้ง document_name แล้วผูก event print_page ทุกขนาดเป็นร้อยส่วนของนิ้ว นับจากมุมกระดาษ:

fn draw_page(&mut self, ui: &MainWindowUi, e: &phai_ui::print::PrintPageEventArgs) {
    let m = e.margin_bounds;                     // พื้นที่ในขอบกระดาษ
    e.set_font("Leelawadee UI", 16, true, false);
    e.draw_text(&format!("ใบเสร็จ หน้า {}", e.page), m.x, m.y);
    e.draw_line(m.x, m.y + 40, m.right(), m.y + 40);
    e.set_has_more_pages(e.page < 3);           // ยังมีหน้าต่อไปไหม
}
  • ui.report.print_preview() หน้าต่างดูตัวอย่าง พลิกหน้าได้ มีปุ่มพิมพ์
  • ui.report.print_dialog() เลือกเครื่องพิมพ์แล้วพิมพ์, ui.report.print() พิมพ์เลยไม่ถาม, ui.report.page_setup() ตั้งกระดาษและขอบ
  • ui.report.print_to_file("Microsoft Print to PDF", path) ได้ไฟล์ PDF
  • วาดได้: draw_text, draw_text_in (ตัดบรรทัด ชิดซ้าย กลาง ขวา), draw_line, draw_rect, fill_rect, draw_image, measure_text, set_color

ผูกข้อมูลกับ control (DataBindings)

วาง component Binding source ให้ข้อมูลมาจากตารางในฐานข้อมูล (ตั้ง bind เหมือนตาราง grid) หรือจากโค้ด (ตั้ง fields = "name, phone" แล้ว ui.people.set_rows(...)) จากนั้นที่ control แต่ละตัวตั้ง DataBindings เป็น people.name

  • กล่องข้อความแสดงข้อความ, ช่องติ๊กแสดงค่าจริงเท็จ, ช่องตัวเลขแสดงตัวเลข, ช่องวันที่แสดงวันที่
  • เลื่อนแถว: move_next(), move_previous(), move_first(), move_last() ค่าที่พิมพ์ในช่องกลับเข้าแถวเอง
  • แถวใหม่ add_new(), ลบ remove_current(), บันทึกลงฐานข้อมูล ui.save_people(), โหลดใหม่ ui.reload_people()
  • event position_changed ทำงานเมื่อแถวปัจจุบันเปลี่ยน

User control: control ของเราเอง

  1. Project > เพิ่ม User Control... ตั้งชื่อ เช่น AddressBox ได้ฟอร์มเล็ก ๆ ที่ออกแบบได้เหมือนฟอร์มทั่วไป และมีไฟล์โค้ดของตัวเอง
  2. เปิดฟอร์มอื่น เลือก User control จากกล่องเครื่องมือ (หมวด Containers) วางลงฟอร์ม หน้าออกแบบแสดง control ข้างในให้เห็น
  3. เข้าถึง control ข้างในจากโค้ดของฟอร์ม: AddressBoxUi::with(ui.home, |a| a.street.text())
  4. ให้ user control บอกฟอร์มว่ามีอะไรเปลี่ยน: ในโค้ดของ AddressBox เรียก ui.notify_parent() ฟอร์มจะได้ on_change ของมัน
ตารางเทียบทุก property เมธอด และ event กับ WinForms อยู่ใน docs/winforms-parity.md ของโปรเจกต์ Phai Studio
