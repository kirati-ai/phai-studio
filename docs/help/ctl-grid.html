Rust Language

1. เริ่มต้นกับ Rust 2. ตัวแปร ชนิดข้อมูล ฟังก์ชัน 3. เงื่อนไขและการวนซ้ำ 4. Ownership และการยืม 5. struct, enum และ match 6. จัดการข้อผิดพลาด 7. Vec, String, HashMap 8. trait และ generic 9. โมดูล crate และเทสต์ 10. อ่าน error ของคอมไพเลอร์ 11. เธรด และก้าวต่อไป

ตารางข้อมูล (DataGridView)

ในกล่องเครื่องมือ: ตารางข้อมูล · เทียบกับ WinForms: DataGridView

ตารางที่ผู้ใช้พิมพ์แก้ในช่องได้ เพิ่มแถวที่ท้ายตารางได้ เรียง กรอง ค้นหา และผูกกับฐานข้อมูลได้ - control ที่เก่งที่สุดของ Phai Studio สำหรับงานข้อมูล (ถ้าแค่แสดงรายการ ใช้ ListView ก็พอ)

  • กำหนดคอลัมน์ใน Columns และตั้งค่าแต่ละคอลัมน์ (ชนิด รูปแบบตัวเลข ผลรวม …) ด้วยปุ่ม Grid Columns ในตัวออกแบบ
  • rows_add ใส่แถว · rows() อ่านทุกแถว · cell / set_cell ทีละช่อง (แถว, คอลัมน์ นับจาก 0)
  • ส่งออกได้ในคำสั่งเดียว: export_xlsx (Excel), export_pdf, export_csv และ print_preview
  • ผูกกับตารางในฐานข้อมูลได้ - ดู ทำงานกับฐานข้อมูล

อยู่ในกล่องเครื่องมือกลุ่ม ข้อมูล (Data) - ลากมาวางบนฟอร์ม แล้วตั้ง Id (ชื่อที่ใช้ในโค้ด) ในหน้าต่าง Properties · ในโค้ดเรียกมันว่า ui.ชื่อId ซึ่งเป็นชนิด phai_ui::ctl::Grid

ตัวอย่าง

1. ใส่แถว

fn loaded(&mut self, ui: &GridDemoUi) {
    ui.scores.rows_add(&["Somchai", "87"]);
    ui.scores.rows_add(&["Malee", "92"]);
    ui.scores.rows_add(&["Narin", "78"]);
}

2. คำนวณจากทุกแถว

rows() ได้ Vec<Vec<String>> - แปลงคะแนนเป็นตัวเลขด้วย parse() ช่องที่พิมพ์ไม่ใช่ตัวเลขจะถูกข้ามไป:

fn total_clicked(&mut self, ui: &GridDemoUi) {
    // rows(): every row's cells, as typed - a score typed wrongly is left out.
    let scores: Vec<f64> = ui.scores.rows().iter().filter_map(|r| r.get(1)?.trim().parse().ok()).collect();
    if !scores.is_empty() {
        let average = scores.iter().sum::<f64>() / scores.len() as f64;
        ui.result.set_text(&format!("Average {average:.1}"));
    }
}

3. เรียงด้วยโค้ด

เหมือนคลิกหัวคอลัมน์ - false คือมากไปน้อย:

fn best_clicked(&mut self, ui: &GridDemoUi) {
    ui.scores.sort_by(1, false); // column 1 (Score), largest first
}

หน้าต่างตัวอย่างทั้งหมด: grid_demo.phaiform กับ grid_demo.rs ในโปรเจกต์ docs/help-src/examples/controls - รันด้วย cargo run -- grid

Events

ดับเบิลคลิกชื่อ event ในแท็บ Events ของ Properties แล้ว Phai Studio จะเขียน method ให้ (ชื่อในตารางนี้สมมติว่า Id ของมันคือ grid และอยู่บนฟอร์ม MainWindow) - ชี้เมาส์ที่ชนิดของ e เพื่อดูชื่อเต็ม
