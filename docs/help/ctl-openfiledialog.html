Rust Language

1. เริ่มต้นกับ Rust 2. ตัวแปร ชนิดข้อมูล ฟังก์ชัน 3. เงื่อนไขและการวนซ้ำ 4. Ownership และการยืม 5. struct, enum และ match 6. จัดการข้อผิดพลาด 7. Vec, String, HashMap 8. trait และ generic 9. โมดูล crate และเทสต์ 10. อ่าน error ของคอมไพเลอร์ 11. เธรด และก้าวต่อไป

หน้าต่างเปิดไฟล์ (OpenFileDialog)

ในกล่องเครื่องมือ: หน้าต่างเปิดไฟล์ · เทียบกับ WinForms: OpenFileDialog

หน้าต่างเลือกไฟล์ที่จะเปิดของ Windows เอง ผู้ใช้คุ้นเคย ไม่ต้องสร้างเอง

  • Filter: ชนิดไฟล์ที่แสดง เขียนเป็นคู่ ชื่อ|รูปแบบ คั่นด้วย | เช่น Text files|*.txt|All files|*.*
  • Title ข้อความบนแถบชื่อ · InitialDirectory โฟลเดอร์เริ่มต้น · Multiselect เลือกได้หลายไฟล์
  • show_dialog() ได้ Option<PathBuf> - None คือกด Cancel

อยู่ในกล่องเครื่องมือกลุ่ม กล่องโต้ตอบ (Dialogs) - ลากมาวางแล้วมันจะไปอยู่ในแถบด้านล่างของตัวออกแบบ (ไม่ได้อยู่บนหน้าต่าง) · ในโค้ดเรียกมันว่า ui.ชื่อId ซึ่งเป็นชนิด phai_ui::ctl::OpenFileDialog

ตัวอย่าง

1. เปิดไฟล์ข้อความ

let … else { return } ออกเลยถ้ากด Cancel แล้วอ่านไฟล์ด้วย std::fs::read_to_string:

fn open_clicked(&mut self, ui: &OpenfiledialogDemoUi) {
    // None: the person pressed Cancel.
    let Some(path) = ui.open_dialog.show_dialog() else { return };
    match std::fs::read_to_string(&path) {
        Ok(text) => {
            ui.contents.set_text(&text.replace('\n', "\r\n"));
            ui.set_title(&path.display().to_string());
        }
        Err(e) => ui.contents.set_text(&format!("Could not read it: {e}")),
    }
}

หน้าต่างตัวอย่างทั้งหมด: openfiledialog_demo.phaiform กับ openfiledialog_demo.rs ในโปรเจกต์ docs/help-src/examples/controls - รันด้วย cargo run -- openfiledialog

Method ของ OpenFileDialog

Methodทำอะไร
show_dialog(&self) -> Option<PathBuf>เปิดหน้าต่าง ได้ไฟล์ที่เลือก - None เมื่อกด Cancel
show_dialog_multi(&self) -> Vec<PathBuf>เปิดหน้าต่างแบบเลือกได้หลายไฟล์ (Multiselect) ได้ทุกไฟล์ที่เลือก

ตั้งได้ในหน้าต่าง Properties เมื่อเลือกมันบนฟอร์ม - ตารางนี้สร้างจาก Phai Studio เอง จึงตรงกับที่เห็นในโปรแกรมเสมอ

Propertyค่าเริ่มต้นทำอะไร

Events

ดับเบิลคลิกชื่อ event ในแท็บ Events ของ Properties แล้ว Phai Studio จะเขียน method ให้ (ชื่อในตารางนี้สมมติว่า Id ของมันคือ openfiledialog และอยู่บนฟอร์ม MainWindow) - ชี้เมาส์ที่ชนิดของ e เพื่อดูชื่อเต็ม
