ตกแต่งหน้าตาด้วย CSS

สีพื้น สีตัวอักษร เส้นขอบ มุมมน และตัวหนา ของทุกปุ่มทุกช่องในโปรแกรม มาจากไฟล์ theme.css ไฟล์เดียว แก้ที่เดียวแล้วเปลี่ยนทั้งโปรแกรม ไม่ต้องไล่แก้ทีละปุ่ม

ทำไมใช้ CSS

ถ้าเคยทำเว็บมาก่อน จะคุ้นกับ CSS อยู่แล้ว Phai Studio ใช้ CSS ส่วนเล็ก ๆ ที่พอสำหรับบอกว่า control แต่ละแบบ หน้าตาเป็นอย่างไรในแต่ละสถานะ ตัว control ยังเป็นของ Windows จริงทุกตัว CSS แค่บอกสีกับเส้น

  • ทั้งโปรแกรมเป็นสไตล์เดียวกัน ปุ่มทุกปุ่มหน้าตาเหมือนกัน เพราะมาจากกฎเดียวกัน
  • เปลี่ยนธีมง่าย อยากได้สีหลักเป็นสีน้ำเงิน แก้บรรทัดเดียว
  • เห็นผลทันที บันทึกไฟล์ CSS แล้วหน้าต่างที่เปิดอยู่เปลี่ยนตามเลย ทั้งในตัวออกแบบและในโปรแกรมที่กำลังรัน

ไฟล์ theme.css อยู่ตรงไหน

ตอนสร้างโปรเจกต์ใหม่ Phai Studio ใส่ theme.css ไว้ในโฟลเดอร์โปรเจกต์ให้แล้ว เป็นธีมมาตรฐานสีสว่าง มีคำอธิบายทุกบรรทัด เปิดจากหน้าต่าง Project แล้วแก้ได้เลย ตอน build ธีมถูกรวมเข้าไปในโปรแกรม ไม่ต้องแจกไฟล์ CSS แยก

เมนู Themeทำอะไร
New theme from the standard...สร้าง theme.css จากธีมมาตรฐาน ข้างไฟล์ฟอร์ม (ฟอร์มต้องบันทึกก่อน)
Import CSS...เลือกไฟล์ CSS ที่มีอยู่แล้ว Phai Studio คัดลอกเข้าโปรเจกต์ให้ แล้วใช้เป็นธีม
No themeเลิกใช้ไฟล์ธีม กลับไปใช้ธีมในตัว
เมนู View > Light / Dark เปลี่ยนสีของตัว Phai Studio เอง ไม่เกี่ยวกับธีมของโปรแกรมที่คุณสร้าง

หน้าตาของกฎ

:root { --accent: #12855f; }

button          { background: #ffffff; border-color: #d4d4d4; border-radius: 4px; }
button:hover    { background: #e7f3ef; border-color: var(--accent); }
button.primary  { background: var(--accent); color: #ffffff; }
#save           { font-weight: 600; }

อ่านว่า: ปุ่มทุกปุ่มพื้นขาว ขอบเทา มุมมน 4 พิกเซล พอเอาเมาส์ชี้ให้พื้นเป็นเขียวอ่อน ปุ่มที่มี class primary เป็นปุ่มสีเขียวตัวหนังสือขาว และปุ่มที่ id เป็น save ให้ตัวหนา

ตัวเลือก (selector)

เขียนแบบนี้หมายถึง
buttoncontrol ทุกตัวชนิดนั้น: window label button checkbox radio edit combo list group tabs toolbar statusbar date progress slider menubar tree (ช่องตัวเลขนับเป็น edit)
*ทุก control
.primarycontrol ที่ใส่ class นี้ไว้ ในช่อง Class ของหน้าต่าง Properties
#savecontrol ตัวเดียว ตาม Id ของมัน
:hover :pressed :focus :disabled :selected :checkedสถานะ: เมาส์ชี้ กดค้าง กำลังพิมพ์ ใช้ไม่ได้ ถูกเลือก ถูกติ๊ก ใส่ต่อกันได้ เช่น button.primary:hover
button, labelหลายตัวเลือกใช้กฎเดียวกัน คั่นด้วยจุลภาค

กฎที่เจาะจงกว่าชนะ: id ชนะ class และสถานะ ซึ่งชนะชนิดของ control ถ้าเจาะจงเท่ากัน กฎที่อยู่ล่างกว่าชนะ เหมือนในเว็บ

ไม่มี a b หรือ a > b (ตัวเลือกแบบซ้อนกัน) เพราะหน้าต่างของ Windows วาง control แบน ๆ ไม่ได้ซ้อนเป็นชั้นแบบหน้าเว็บ กฎแบบนั้นจะเดาผลยาก

สิ่งที่ตั้งได้

propertyค่า
background color border-colorสี: #rgb #rrggbb #rrggbbaa rgb(r, g, b) ชื่อสีอย่าง white black transparent หรือ var(--ชื่อ)
border-width border-radiusพิกเซลที่ขนาดจอ 100% เช่น 4 หรือ 4px
accent-colorสีเครื่องหมายถูก จุดของ radio และเส้นใต้แท็บที่เลือก
icon-colorสีไอคอนในแถบเครื่องมือ
font-size font-weightขนาดเป็น point เช่น 10pt และความหนา 400 600 700 หรือ bold

ตัวแปร: เปลี่ยนสีหลักทั้งโปรแกรมในบรรทัดเดียว

ตั้งค่าไว้ใน :root แล้วเรียกใช้ด้วย var(--ชื่อ) ธีมมาตรฐานใช้ --accent เป็นสีหลัก เปลี่ยนตัวเดียว ปุ่ม แท็บ และช่องที่ถูกเลือก เปลี่ยนตามหมด

:root { --accent: #2563eb; }   /* จากเขียวเป็นน้ำเงิน */

แก้นิดเดียว ไม่ต้องคัดลอกทั้งไฟล์

ถ้าชอบธีมมาตรฐานอยู่แล้ว แค่อยากเปลี่ยนบางอย่าง เขียนไฟล์ของตัวเองสั้น ๆ แบบนี้ได้

@import "phai:light";          /* หรือ "phai:dark" ธีมมืด */

:root  { --accent: #2563eb; }
button { border-radius: 10px; }

@import "other.css"; ดึงไฟล์อื่นที่อยู่ข้างกันเข้ามาได้ด้วย

แก้ทีละตัวในหน้าต่าง Properties

ในหัวข้อ Appearance ของหน้าต่าง Properties มี Back colour, Fore colour, Border colour, Corner radius และ Font ตั้งให้ control ตัวเดียวได้ ค่าที่ตั้งตรงนี้ทับธีม เหมาะกับจุดพิเศษที่มีจุดเดียว ถ้าหลายตัวต้องหน้าตาเหมือนกัน ใส่ class ให้ทั้งหมด แล้วเขียนกฎใน CSS ทีเดียวดีกว่า

ถ้าเขียนผิด

ถ้า CSS มีจุดที่อ่านไม่ออก Phai Studio จะบอกว่าผิดบรรทัดไหน และหน้าต่างใช้ธีมเดิมไปก่อน ไม่ข้ามกฎที่ผิดไปเงียบ ๆ เพราะธีมที่ใช้ได้ครึ่งเดียว จะดูเหมือน control เสีย

ลองทำ

  1. ลากปุ่มลงฟอร์ม ในหน้าต่าง Properties พิมพ์ danger ในช่อง Class
  2. เปิด theme.css แล้วเพิ่มกฎ button.danger { background: #dc2626; color: white; } บันทึกไฟล์
  3. ดูปุ่มในตัวออกแบบเปลี่ยนเป็นสีแดง แล้วลองเพิ่ม button.danger:hover ให้สีเข้มขึ้นตอนเอาเมาส์ชี้

ภาพเคลื่อนไหว: animation และ @keyframes

transition ทำให้สีค่อย ๆ เปลี่ยนตอนสถานะเปลี่ยน (เช่น เอาเมาส์ชี้) ส่วน animation ทำให้สีเคลื่อนไหวเองโดยไม่ต้องรอใคร ซ้ำไปเรื่อย ๆ หรือกี่รอบก็ได้ เหมาะกับปุ่มที่อยากให้คนเห็น หรือสถานะเตือน

/* สำเร็จรูป: blink (ตัวหนังสือกะพริบ) pulse (พื้นเต้นเป็นสี accent) fade-in (ค่อย ๆ ปรากฏ) */
button.urgent { animation: pulse 1.5s infinite; }
#warning      { animation: blink 1s infinite; }
#panel        { animation: fade-in 400ms; }

/* ทำเอง */
@keyframes alarm {
  50% { background: #dc2626; color: #ffffff; border-color: #991b1b; }
}
#stop { animation: alarm 2s ease-in-out infinite alternate; }
ส่วนของ animationหมายถึง
ชื่อblink pulse fade-in หรือชื่อ @keyframes ที่เขียนเอง
เวลาแรกหนึ่งรอบนานเท่าไร เช่น 1s 400ms เวลาที่สองคือรอก่อนเริ่ม
easingease linear ease-in ease-out ease-in-out
จำนวนรอบตัวเลข หรือ infinite ไม่หยุด (ไม่ใส่ = รอบเดียว)
alternateรอบคู่เดินย้อนกลับ ไปกลับนุ่ม ๆ

ใน @keyframes เขียน from, to หรือเปอร์เซ็นต์ (0%, 100% { } ก็ได้) เฟรมที่ไม่ได้เขียนใช้หน้าตาปกติของ control ขยับได้เฉพาะสี (background color border-color accent-color icon-color) และ border-width เพราะ control ของ Windows หมุนหรือโปร่งใสแบบหน้าเว็บไม่ได้ fade-in จึงเป็นการค่อย ๆ เปลี่ยนสีจากสีพื้นหน้าต่าง

ไม่ต้องเขียน CSS เองก็ได้: เลือก control แล้วไปที่แท็บ Style 🖌 ในหน้าต่าง Properties มีช่อง Animation ให้เลือกแบบสำเร็จรูป (ใช้กับปุ่ม ช่องติ๊ก radio ช่องกรอก slider และ progress)
